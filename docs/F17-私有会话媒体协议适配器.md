# F17 私有会话媒体协议适配器（未启动）

新增可供主进程使用的媒体协议注册／清理适配器，复用临时探测能力注册表。没有调用应用入口、创建 Session 或 BrowserWindow、修改全局协议权限、打开网络或启用界面。

## 必须由宿主保证的条件

宿主必须为每个探测窗口及其唯一文档创建一个独占的内存私有 Session，并提供基于真实主进程对象的绑定验证器。不能传默认 Session、持久化 Session，不能与其他窗口、文档或任务共用。只从原始 Request 推测 window/document 身份是不可靠的，本适配器不这样做。

适配器检查非持久化、无存储目录、没有已有 app handler，并防止在本模块内再次使用同一 Session 或协议对象。此检查不能证明整个 Electron 应用没有其他消费者；独占性必须由宿主创建和生命周期管理保证，不是由一个布尔声明或URL证明。

## 路由与清理

- 默认仅接收规范 `app://video/<小写UUID>` 的 GET／HEAD，固定使用创建时的可信 owner/document 调用能力注册表。不接受请求带入的身份、路径、远端地址或历史文件查找。可选的可信构建资源加载器现可在同一 handler 中服务固定探测页与受限 JS，见 [同会话路由](F17-私有探测页媒体同会话路由.md)。
- 请求时再次验证宿主独占绑定。其他地址和未绑定能力不可读取；不会转发到默认协议、磁盘路径或网络。
- 清理先失效适配器和 owner 的能力，再解除本私有 Session 的 app handler。清理结果必须区分逻辑失效与 unhandle 是否成功，不隐瞒注销失败。
- 清理期间异步取得的来源由注册表拒绝并关闭；响应尚未交付时复核失效状态，取消其正文再返回不可用。
- 已经交付的响应流仍由自身结束／取消机制关闭，不宣称此适配器强制终止所有活跃流。私有 Session／窗口本身的销毁仍属宿主责任。

## 未接入项

当前无实际宿主构造私有分区、探测窗口或文档生命周期的接线。还需确认原生加载方式、CSP、受限协议权限和真实解码，再决定是否启用。单元测试采用模拟 Session／协议对象与真实软件能力注册表，不证明 Electron 原生协议注册、Windows窗口隔离或视频播放已通过。

若原生 handle 在安装过程中抛错，适配器不能确认注册结果：它会逻辑失效并撤销owner能力，禁止该Session／协议对象重用，但不冒称handler已经移除。宿主必须丢弃该专属探测上下文；本切片不替宿主销毁窗口或Session。

新增4项模拟会话回归，覆盖固定Session对象与冻结owner、跨文档能力拒绝、规范URL、永久禁止复用、持久化／已有handler／宿主未绑定拒绝、异步清理关闭来源、未交付正文取消及安装／注销不确定。全量345/345（0失败、0跳过）、类型检查、构建及差异检查通过。独立静态审查无阻断；测试没有启动原生Electron会话。
