# F10 固定格式预览

本轮提供本地确定性的格式整理，不是模型生成。输出内容来自当前任务风格、已经填写的镜头字段及该镜头实际关联的资产；不会复制范例人物、服装、场景、设备、时长或动作设计。

## 结构与来源

全局信息保持固定顺序：画质风格、影片基调、光线设计、角色绑定、色彩锚点、场景锚点、人物视觉锚点。任务风格沿用现有继承／覆盖规则，视频／镜头的补充说明作为用户原文单独列出，不自行拆解为光线、色彩或镜头参数。

镜头按叙事顺序编号与标题展开，包含时长、镜头、描述内容、适用的动作要求／节奏、声音设计及连续性约束。已有画面、景别、运镜、动作和声音字段如实使用；时长等缺失结构明确标记未填写，不将整片参数按镜头分摊，不补写台词或摄影设备。

整条视频按现有镜头顺序组合，负面约束只在调用方明确提供时追加，不生成默认负面提示词。每镜只使用本镜实际关联资产；整片全局信息仅汇集所含镜头的关联资产，未关联资产不混入。

## 首尾静态图

分别选择第一个与最后一个镜头的身份及关联资产名称，保留已有景别作为构图参考。资产自由描述和任务自由风格说明可能包含动态叙述，因此不自动搬入静态图。独立静态构图和起始／结束状态只能采用明确提供的字段；当前工作区尚无这些字段，界面默认预览明确标记未提供。已有参考图只提示已关联，不能推测上传图编号或用内部 UUID 代替人物绑定。

不从动态画面描述或动作推测起止状态，不搬入镜头动作、运镜、声音、时长或时间线。首尾字段独立，不互相复制；只有一个镜头时可以指向同一镜头，但仍分别留待填写首／尾状态。

## 界面与保存边界

提示词面板在现有四类提示词下增加可展开的只读格式预览，以及明确点击的复制操作。复制仅写系统剪贴板，不填回现有提示词，不改变核对、历史版本或图片确认。用户可另行手动编辑，仍走原保存规则。

预览反映当前编辑，可能尚未保存；缺失项不是模型结果。复制失败提示手动选择文本，重复点击被合并，切换类型或关闭后不会把旧异步反馈显示到新预览。

纯格式器允许明确传入额外结构字段，以便后续受控编辑使用；本轮不新增这些字段的数据库持久化，也不增加临时填写表单、自动采用或真实提供方。

## 验证范围

实现为 `formatPromptTemplate(workspace, planStyle, kind, shotId, fields?)`，额外字段仅显式接收：基调／光线／色彩、逐镜头时长／动作要求／节奏／连续性、分别的首尾静态构图与状态、整片负面约束。界面本轮不提供这些新增字段表单，缺失时显示“未提供”。既有提示词正文仍保留在原编辑框，格式器不把它当作模型返回重写。

新增 4 项合成测试：字段顺序／镜头次序／资产范围与原稿不变；显式字段和风格继承／覆盖；静态首尾隔离与动态字段排除；空／单镜头／删除镜头／无关布局等边界。定向 4/4、全量 `npm test` 178/178（0 失败、0 跳过），类型检查、生产构建及 `git diff --check` 通过；独立只读复审及定向 4/4 通过。构建仍有既存第三方 `use no memo` 非阻断警告。

界面预览／复制已接入并通过类型与构建检查；异步复制保护经代码审查，不宣称实际按钮／剪贴板运行已验收。未运行 Windows／原生剪贴板／实际界面或真实生成验收，不使用真实剧本文本或模板范例。

本模块不使用 DeepSeek 或其他外部 API。剧本转分镜的提供方属于独立流程，不改变这里的确定性格式整理；后续视频提供方仍需单独验证已确认素材与提示词的提交链。
