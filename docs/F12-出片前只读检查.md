# F12 / F13 出片前只读检查

首尾帧审核页新增「出片前检查 / 不提交」只读摘要。依据现有任务模型和自动保存状态，展示已保存任务修订、视频提示词原文及版本、F12 确认是否与当前输入一致，以及首尾各自的候选／图片 ID、尺寸和预览状态。两个位置使用同一归档图片时仍分列两个角色。

## 不把草稿当已保存输入

未保存、保存中、保存失败或冲突未解决时隐藏上述详情，提醒先处理保存；不自动保存、不改写本地草稿、不替换提示词、不确认素材。使用现有自动保存控制器的修订和状态，没有独立缓存或新的持久化。重开从既有保存数据重建摘要，图片加载状态仍需本次重新观察。

## 明确的能力边界

renderer 现有图片模型没有内容摘要，因此不能展示或声称验证了 SHA256 封存值。本页仅展示记录身份，明确说明媒体摘要须由主进程在未来发送前重新校验。图片预览加载成功不等于文件此刻仍完整，也不等于可发送。

所有账号登录、免费状态、首尾模式和输入能力均标为未验证；附加素材没有产品级选取／确认入口，不自动采用关联资产。真实提交和队列未接入。没有账号选择、能力查询、预检 IPC、发送按钮、执行记录或网络请求，DeepSeek 不参与。

当前页面不是既有 `VideoPreflight` 的运行结果，不是提交授权。F13 真实业务保持 L0；真正接线仍需官方入口验证及再次核验输入、账号和能力。
