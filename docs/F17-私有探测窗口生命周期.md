# F17 私有探测窗口生命周期（尚未启用）

新增主进程专用 Electron 窗口工厂，供后续宿主组合暂存候选、私有协议及固定探测页使用。应用入口没有调用它，也没有新增全局 scheme 权限、产品按钮或默认会话路由。

## 可信宿主契约

工厂仅接收主进程提供的规范能力 UUID，不接收任意页面地址、磁盘路径或 renderer 身份。每次创建新的非持久化分区和专用沙箱窗口，禁用 Node 与 preload，以实际 webContents 与 Session 对象及新的文档身份建立绑定。

固定页面为 `app://video-probe/f17-video-probe.html#<UUID>`。调用者必须在加载前安装并确认该专属会话的可信组合路由。当前仅服务 `app://video/<UUID>` 的旧适配器不能与另一个 `app` handler 同时安装，不能用它冒充完整页面路由。路由宿主须只返回受包管理的固定页面／资源和当前 owner 的能力响应，不能转发任意文件或网络。工厂不替宿主证明安装回调返回的声明。

## 生命周期及限制

只允许初次固定文档加载；后续导航、重载、崩溃、取消及关闭使绑定失效，并清理专用窗口和路由。拒绝弹窗，不复用用户主窗口，不影响其他窗口。清理失败不得报告为已成功注销或销毁。

尚未连接原生协议权限、打包页路由与结果采集，也未完成 Windows 实际加载／解码验收。模拟 Electron 对象的测试只能证明工厂调用和状态约束，不等于原生安全隔离认证。能力撤销阻止后续取得来源，不承诺撤回已经交付的响应流。

## 验证记录

4 项注入式生命周期测试覆盖固定 URL、窗口配置、拒绝权限／弹窗、会话禁止复用、导航及同页变更、重载、崩溃、加载期间取消、安装中同步关闭后晚返回清理、销毁／路由注销失败。独立审查和聚焦 4/4 通过；全量 360/360（0 失败、0 跳过）、类型检查、构建及差异检查通过。

外部资源拒绝仍是可信路由安装器及页面 CSP 的必需责任，本工厂没有安装 webRequest 网络过滤器。安装回调抛错可能留下未知的原生注册结果，错误明确标注路由清理未确认；专属会话不可复用。窗口关闭也不表示所有原生网络活动已经终止或会话数据已经物理清除。
