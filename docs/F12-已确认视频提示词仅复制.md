# F12 已保存视频提示词仅复制

V1.19 云端增量，基于 d1a0b8f。现有“出片前检查 / 不提交”已展示保存的视频提示词，本轮只增加明确复制原文的手工核对出口，不接入视频发送。

## 可用条件与范围

要求当前任务已保存且无保存中、错误或冲突，F12 本地确认与当前输入一致，视频提示词可用，首尾角色的当前图片记录属于本任务且预览已加载。缺失、替换、刷新待加载或读取失败不允许开始复制。复制的文字是已保存视频提示词原文，不拼接摘要、模板、图片编号或额外素材。

按钮明确标记“仅复制 / 不提交”。不会写入工作区、改变提示词版本、确认图片、创建队列、打开提供方或提交任何内容。图片预览 ready 仅作为本地显示门禁，不替代文件摘要／真实上传校验，也不代表账号、免费额度或提供方能力已验证。

## 异步边界

复制操作绑定任务、修订、确认、当前图片身份及加载代次；重复操作、来源变化、关闭或卸载不能让旧完成回调宣称新内容复制成功。浏览器已经接收的剪贴板写入无法撤销，所以来源变化后只能抑制过期反馈，不能承诺追回已写入系统剪贴板的旧文字。后续复制前需重新核对当前内容。

## 验证

新增 2 项合成回归，覆盖原文含首尾空白精确保留、重复请求、保存状态／本地确认／本任务图片加载门禁，以及延迟 Promise 完成后的任务修订、加载代次、A→B→A、取消重开令牌失效。延迟测试调用的是状态器完成方法，不是浏览器剪贴板或 React 集成。全量 `npm test` 271/271（0 失败、0 跳过）、`npm run build`（含类型检查）及 `git diff --check` 通过。独立复审无阻断，纯测试 2/2 通过。合成文本及状态测试不等于真实系统剪贴板、原生窗口或 Windows 验收。
