# F17：本地 MP4 暂存字节快照

内部主进程适配器承接[本地 MP4 接收](F17-本地MP4接收适配器.md)。宿主必须明确指定一个已存在、可信、专用且规范的本地暂存目录；没有默认目录或回退。适配器记住目录身份，仅独占新建一个随机名称的文件，不扫描旧暂存目录。

暂存逐块复制已通过结构检查的输入，对照确切字节数、SHA-256 和 8 GiB 上限；刷盘后从同一打开句柄重新读取并校验暂存内容，再关闭并复查路径及文件身份。成功仅返回主进程可见的暂存路径、文件身份、字节指纹和专用清理函数。后续解码必须重新核对这些绑定，不得将结构检查或字节一致当成解码成功。

取消、源文件变化、损坏或写入失败不会返回快照。清理仅操作该次排他创建且身份可核实的文件；若目录、文件或已验证快照发生替换，不触碰不明文件，报告保留或未知。取消由可信源和暂存协作，不会强制中止任意挂起的外部生成器。规范目录检查及身份复核不是对恶意同用户文件系统操作的沙箱，也未验证所有 Windows 重解析点。

暂未接原生界面、真实解码、成片发布、数据库、网络或远程平台。不修改输入文件。仅使用合成 MP4 结构和临时文件测试，无实际视频、Windows 或用户数据。

## 快照到临时探测

仅可信主进程可将返回快照自带的 `acquire` 与同一个 `fingerprint` 交给 `VideoProbeRegistry`。不接受解码器或渲染端提供的路径。每次获取复核暂存根、文件绑定及整文件 SHA-256；返回的单次范围流只读取同一个获准句柄，每块读前后检查身份。结束、取消或失败释放句柄，单快照同时持有的获取及读取名额合计最多八个。范围处理有固定内存开销，但完整字节复核仍会读取整个文件。

快照清理立即阻止新获取，等待正在获取的句柄收尾并关闭仍在使用的句柄，再按原绑定清理；不会把所有权不明的文件删除。登记过期或撤销导致未移交的请求无法取得响应体，登记本身不会自动删快照，也不会中止已移交的流；宿主负责调用快照清理。这里只验证本地字节传递，不证明实际解码、生产播放或 Windows 支持。
