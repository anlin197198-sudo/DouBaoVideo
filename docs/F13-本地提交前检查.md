# F13 本地视频提交前检查契约

本轮只提供未接线的非网络检查边界，不创建执行记录、队列或发送请求，不启动客户端或账号会话。没有真实豆包适配器，不能据此声称已提交、可免费生成或后续发送已获授权。DeepSeek 不参与视频侧。

## 已保存输入

检查以指定任务及预期修订为范围，读取已保存工作区、当前计划风格和账号状态，不接受渲染器自行拼装的“已确认”布尔值。F12 确认必须与当前完整输入一致，未失效；视频提示词使用同一次确认对应的原文与版本，绝不重新格式化、生成或替换。

首帧和尾帧按两个独立角色读取当前候选，校验任务归属、归档完整性，记录候选／图片身份、字节数和内容摘要。允许用户为两角色明确选择同一归档图片，但不会合并角色、调换位置或把角色名当作不同图片的证明。输出只含本地封存元数据，不带磁盘路径或可变图片字节。这不是数字签名或服务器凭证，也不能由调用方缓存后直接授权发送。

## 能力证据

生产调用方必须提供独立、可信且仍有效的账号登录、免费状态、目标入口角色及参数能力证据。账号手动标注的档位／登录／可用状态不是这些证据。未知、付费、缺失、账号或提供方不匹配、过期及未来时间证据均应阻止检查通过。

本轮只有合成证据适配器用于测试，没有官方能力查询或实际提供方实现。SQLite 检查与短同步读取不跨异步等待，输出也不替代未来真正发送时的状态及内容再验证。

## 额外素材

调用方必须显式列出选中的额外素材和必需的额外素材，即使没有也须传空数组，不能把漏传当作“不需要”。当前数据没有额外素材独立的明确确认记录，资产关联或参考图存在都不能冒充提交确认。

因此本切片遇到任何额外素材声明均阻止，不静默删除、不降级发送。已另增未接线的[附加素材内存确认草稿](F13-附加素材确认草稿.md)，但没有产品级持久确认或官方角色验证，本预检分支仍维持阻止。未来须验证官方入口支持对应角色、类型与数量，并完成用户确认及发送前复核，才可接线。

## 成功及失败语义

检查成功仅表示该时点、该信任边界内形成了本地元数据快照。它没有传输数据、清理会话、分配账号、写入执行回执或触发视频生成。失败返回固定原因，不回显任意适配器异常或原文；已有任务、提示词、确认和历史均保持。

真实发送前仍须重新核对任务修订、确认内容、图片封存摘要、账号和当时有效的官方免费能力；缓存检查结果不构成发送授权。

## 验证范围

只用合成 SQLite、PNG 和本地假能力证据。实现位于 [video-preflight.ts](../src/main/application/video-preflight.ts)：构造器显式接收应用数据库、归档服务、同步只读能力证据端口和时钟；`check` 必须提供任务ID、账号ID、预期修订及选中／必需额外素材两个数组。证据严格限定豆包、匹配账号、证据身份、观察／过期时间、已验证登录／免费、首尾角色及支持的比例／时长；适配器缺失或异常不生成成功结果。

返回只有 `blocked` 或 `preflight-only`，两者均 `submitted: false`。通过时冻结任务修订、账号／证据身份、原视频正文／版本／输入快照、确认快照、参数及首尾图片摘要列表。没有新增服务注册、IPC、客户端或执行记录。

新增 [4 项合成集成测试](../tests/video-preflight.test.ts)：原文／版本与同图独立角色、冻结元数据且无数据库／回执写入；缺失／未知／付费／过期／未来／错账号及不支持角色或参数证据；额外素材声明与遗漏拒绝；损坏／外任务图片、陈旧任务／失效确认、归档修复；账号停用／待移除、适配器异常、结束时间过期／无效／倒退及恶意属性读取异常。定向 4/4、全量 `npm test` 182/182（0 失败、0 跳过）、类型检查、生产构建及 `git diff --check` 通过。独立静态复审无阻断，审查者未独立运行文件测试；构建保留既有第三方 `use no memo` 非阻断警告。真实 Windows、豆包登录、首尾上传位置、能力限制、提交／跟踪、队列及用户验收仍未完成。F13 的实际视频业务继续为 L0 未开发，不因该内部契约提高完成率。
