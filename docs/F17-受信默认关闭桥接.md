# F17 受信默认关闭桥接边界

本轮先整合主进程原生选择器适配与能力注入式界面，再加入仅供未来可信宿主调用的路由对象。它没有注册 IPC、没有 preload 暴露、没有环境开关，也没有向普通成片页面传入能力。普通应用仍是只读元数据列表。

`createLocalImportRoute` 的 `enabled` 默认关闭；即使传入命令，没有可信主进程显式启用也不能调用。readiness 只返回固定 available 布尔值，不能因探测 readiness 创建窗口、选择文件或修改工作区。

路由校验真实 sender 对象、捕获的主 frame 对象、当前主 frame、准确页面 URL（含 query/hash）、窗口／webContents 存活、文档代次。旧 frame、外国窗口、子 frame、旧代次和页面更换不能复用能力。请求只接受任务 ID／修订，不接收路径、数据库、脚本、窗口 ID 或权限参数。

导航／关闭／崩溃会撤销路由并发出取消信号，但必须等待真实命令结算；不能把取消等同于没有发布。已返回的归档和记录事实使用固定枚举／布尔白名单投影，contextCurrent 标明结果回来时文档是否仍有效；额外字段被剥离。未知结果或异常保守映射为发布／登记未确认，不泄露异常正文，也不假定没有副作用。该结果是内部契约，不授权向新文档重新投递旧页面结果。

## 未来接线要求，当前未启用

1. 在原生验收后的可信应用宿主中，绑定当前应用拥有的 V7 连接、实际编辑器任务／修订和真实窗口／文档代次，创建原生导入命令；不得把恢复副本或任意数据库当自动导入授权。
2. 为每个实际主文档构造独立路由并管理 close；必须核对绑定窗口和当前 frame，不能根据 renderer 提交的 windowId 或路径选择窗口。
3. 新 IPC/preload 需单独审核：固定通道、readiness、严格任务请求、撤销生命周期、取消请求绑定以及结果脱敏。不得直接把 AbortSignal 作为 Electron 可序列化参数；应由主进程维护请求与取消对应关系。当前没有这种跨进程传输实现。
4. 只有可信 readiness 后才给界面注入 run／refreshRecords 能力；刷新只能读取元数据。任务／页面变化后不得投递旧结果或自动重试。只读回退保持可用。
5. 原生 scheme 权限、私有构建清单／窗口／首帧及对话框成功流程仍需真正验收；本轮没有启动 Electron 或 Windows，也没有启用用户入口。

本轮合成 FFmpeg 烟测仅验证固定测试画面 MP4 的独占归档、准确全量／范围字节及 FFmpeg 全帧解码，不等同 Electron 播放器或用户材料验证。RUN 02 远程待下载恢复仍在独立待办。
