# F17 临时播放探测能力（主进程内部）

为已经由可信主进程固定身份／摘要的暂存候选提供短期读取能力，供后续原生解码探测使用。没有注册 Electron 协议、打开窗口、接入按钮或执行真实播放。

## 边界

- 由主进程签发随机 UUID，地址固定为 `app://video/<小写UUID>`。不接受 renderer 路径、远端URL或历史成片路径，不进行默认文件查找。
- 绑定精确暂存摘要和字节数、窗口身份及唯一文档身份。读取请求同时提供实际请求方身份并检查宿主验证器；只有签发时和读取时都仍有效的原窗口／文档可以取得来源。
- 主机必须在导航、刷新和关闭时主动失效旧 owner，文档身份不能复用。软件校验器不是 Electron 安全来源判断的替代品；实际宿主接线尚未完成。
- 默认30秒，最多120秒、同时最多128项；使用进程内单调时钟，返回deadline不是日历时间。观察到过期或回拨即移除原能力，不能复活。显式撤销或 owner 失效阻止新的读取。异步取得来源后再次核对；若期间过期、撤销或身份改变，关闭取得的来源，不交给响应。响应读取长度或真正取得流前还会复核，覆盖异步取得与响应继续执行之间的微任务间隙。
- 取得来源必须由受信主进程暂存访问器完成，确认返回字节证据与签发证据一致。比较返回摘要本身不能认证不可信访问器，真实适配器仍须验证其固定句柄和字节。
- 复用既有范围响应处理 GET／HEAD。协议传输不是媒体认证；探测候选仍可能无法解码，签发能力不产生“已可播放”结论、成片记录或完成状态。

## 撤销和生命周期限制

已经移交给响应的流仍由来源自己在 EOF／取消／错误时关闭。本切片撤销不能保证中止已经开始的响应流，不宣称暂停、重新启动或强制关闭播放器。后续宿主如要求即时终止已开始的探测，需要额外明确的会话关闭机制。

能力只存在当前主进程内存中，不持久化、不备份，也不从恢复记录重新签发。没有真实窗口、原生媒体解码、用户素材或Windows验收；测试只用合成字节和注入来源。
