# F13 附加素材本地确认草稿

## 边界与产品依据

产品需求第 4 节及开发文档 F13 要求使用同一次确认的首尾图和视频提示词，其他明确采用的关联资产只有目标入口支持才可附送，必需输入不受支持时暂停。本轮没有验证真实豆包输入角色，因而只实现未接线的内部不可变草稿契约。没有 UI、IPC、账号操作、传输、队列或提供方适配器；不改变既有 `VideoPreflight` 对任何附加素材的阻断。DeepSeek 不参与。

关联关系不是提交选择，F12 两图确认也不是附加素材确认。调用方必须明确列出选择，不能自动纳入全部依赖。只可选择当前任务、当前已核对视频提示词所依赖的镜头关联资产。附加参考图不是首帧或尾帧的替代，不改变模式、位置或已确认正文。

## 快照与失效

草稿绑定任务修订、精确视频提示词及确认快照、首尾两个独立图片角色，以及选中资产身份、版本、元数据和归档图片摘要。图片必须实际可读、属于当前任务且内容完整；输出不含图片字节或本地路径。确认前重新读取，拒绝已更改、缺失或损坏输入，不静默丢弃选项。

确认属于本实例内存中的显式操作，不持久化、不跨重启；外部重建对象不能冒充本实例草稿。内部显式确认参数不是来自真实用户的认证证明，未来 UI 必须呈现完整选项并取得实际操作。该快照仅描述检查时点，不是签名、上传授权或未来仍有效的证明。

## 提供方证据与剩余要求

可信内部证据端口必须明确验证相同账号、有效登录、免费状态、首尾模式、参数，以及该模式下允许的附加角色、所选资产类型和明确的数量上限。角色名是本地契约，不是本轮已验证的豆包能力。未知、过期、付费、模式不匹配或不支持类型均不能确认，不降级到其他模式。

在产品接线之前，还须现场验证目标入口、角色及数量限制，设计明确选取／必需素材与用户确认界面、持久化与恢复语义，再将其与发送前重新校验和执行快照联动。本轮不开放真实提交，F13 真实业务仍为 L0。

## 内部接口与验证

实现位于 `src/main/application/extra-asset-draft.ts`。`preview` 必须提供任务 ID、账号 ID、预期修订和非空、不重复的 `selectedAssetIds`；不以空列表表示自动选择。`draft-only` 深冻结快照可包含 `capabilityBlocker`，只供内部预览，不代表支持发送。`confirm(preview, {accepted:true})` 只接受同一服务实例产生的原始预览对象；重新读取输入、摘要并核实能力后返回 `local-confirmed-only`。所有结果均 `submitted:false`。没有删除、替换或改变任何已有确认。

资产封存同时包含现有 `version`、完整元数据指纹与任务修订；节点移动等不影响 F12 的变化，也可能令本草稿保守失效，此时重建草稿，不冒用旧快照。能力端口明确提供 `maxExtraImages`，未知上限不能视为无限。原始角色字符串 `extra-reference-image` 仅为内部抽象，未宣称官方支持。当前没有“必需素材”产品标记；本契约对明确列出的全部选项一视同仁地要求支持，不能把不支持的项目删掉后继续。

4 项合成集成测试覆盖：显式选择、精确提示词及同图双角色、深冻结、无数据库写入、外部复制对象和跨实例拒绝；未知／付费／错模式／错类型／超数量／失效证据；缺失或重复选项、现有未关联资产、外任务图片、文件缺失、损坏及可解码替换；任务修订、资产版本和元数据变化后的拒绝。使用本地合成 SQLite／PNG，不含真实账号或用户素材。

全量 `npm test` 200/200（0 失败、0 跳过）、类型检查、生产构建及 `git diff --check` 通过。独立静态复审无阻断；审查者未独立运行测试。既有第三方 `use no memo` 为非阻断构建警告。无真实 UI／Windows／提供方验收。
