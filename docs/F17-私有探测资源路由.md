# F17 私有探测资源路由（未接协议）

基线 `1f2dec4`。渲染器生产构建现在生成 `out/renderer/f17-video-probe-assets.json`。路由加载器在主进程使用可信打包渲染目录，先将该清单列明的 HTML 与静态 JS 检查后读入内存；不改变既有主界面、WebContents、应用协议或登记。并未启用可访问的私有窗口、应用路由或服务。

- Vite 从唯一 `f17-video-probe` 入口的静态模块图生成固定清单，记录精确文件名、长度、SHA-256。HTML 脚本必须指向唯一入口，modulepreload 必须在模块图内。其他入口、脱离图的资源、动态导入、外链与非预期命名导致构建拒绝，不进入清单。
- 加载不拼接请求路径读盘；只接受固定清单和受限名称，校验真实路径包含关系、不跟随指向另一位置的文件／目录链接，读取固定文件描述符，核验大小及 SHA-256。不使用 `file://`、网络请求、公共路径解析器或正常 renderer/preload 备用机制。全部资产上限 4 MiB、最多 16 个 JS，HTML 最大 32 KiB、单 JS 最大 1 MiB，清单最大 64 KiB。清单是可信产物的一部分，不是对被主动篡改的完整安装包做签名认证。
- 只响应 `app://video-probe/f17-video-probe.html` 与清单所列同源 JS 的 GET/HEAD。普通 URI、查询、片段、任何未知文件、替代域和其他方法返回无正文 404。页面的 fragment 不参与资源请求，也不会进入路由输出；`app://video` 媒体仍由不同的主进程支路处理。
- 响应包括精确内容类型、长度（HEAD 无正文）、不缓存、no-referrer、nosniff 与私有 CSP；CSP 默认拒绝，仅允许同源脚本及 `app://video` 媒体、拒绝请求连接及外层框架。加载失败只抛固定安全诊断，不返回路径、令牌、内容或异常细节。
- API：`createPrivateVideoProbePageLoader(trustedRendererDirectory)(request)`。未来专用宿主可在同一私有会话中和媒体范围路由组合，仍须独立核对窗口／文档绑定、导航与回收，不复用默认会话；本模块不授权请求来源，也不绑定协议。

云端验证仅覆盖合成资源目录、模拟模块图与实际 Vite 构建产物在 Node 读取，尚未运行 Electron/Windows 或实际 ASAR 原生读取，也未观察原生播放。
