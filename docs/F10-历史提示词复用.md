# F10 历史提示词复用

V1.19 云端增量，基于 f783a48。本切片补充开发文档的历史恢复待办，不新增真实模型能力、外部服务或账号操作。

## 操作

在提示词历史中选择已保存版本，查看正文与当时输入快照，点「预览使用此历史版本」。确认区说明只替换这一项及保存后形成新版本，用户可取消。当前编辑未保存、保存中、保存失败或冲突时禁止采用；先保存原稿，确保旧内容已在不可变历史中。

确认后把历史正文与历史输入快照放入当前编辑，按正常自动保存写入。界面只报告“等待自动保存”，用户须查看保存状态，不能把进入草稿当成持久化成功。保存失败沿用现有重试／冲突处理，不静默丢稿。

仅明确选择的提示词类型／镜头改变，其他正文、镜头、资产、布局不覆盖。历史记录永不更新或删除；正常保存版本号递增。若正文与输入快照已相同则无操作、无重复版本。历史详情通过现有任务／类型／镜头限定的只读接口取得，没有新增写 IPC 或数据库迁移。

## 过期输入与审核

- 保留历史输入快照，不调用“已核对当前输入”。依赖已变化时仍显示待更新，由用户单项核对。
- 预览绑定当前提示词、相关输入及图片审核状态；确认期间有变化则拒绝采用，需重新预览。布局变化不影响相关输入。
- 实际复用时将已有图片确认标为失效，包含正文相同但输入快照不同的情况；随后核对回当前输入也不复活旧确认。没有确认的工作区不会凭空生成确认。
- 共享恢复函数只处理经界面限定作用域的历史详情，作用域隔离由既有只读接口和组件任务／类型／镜头生命周期保障，不宣称从无作用域字段的历史正文推断任务归属。
