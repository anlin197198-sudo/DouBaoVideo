# F05 下一步视口定位

V1.19 云端增量，基于 85392a5。依据界面设计“顶部主要按钮切换为下一步并定位相关内容”，仅处理用户明确点击顶部下一步后的视口位置；不引入生成、调度或自动布局。

## 行为边界

仅在当前目标节点存在且离开可见画布区域时定位。保持当前缩放和所有节点手工坐标，正文、提示词版本、素材及审核状态不由定位操作修改。已可见目标不反复平移；非节点目标及无法可靠测量的状态保守跳过。

不会在渲染、任务重开、自动保存或内容变化时自动定位。视口保存继续使用已有移动结束路径，不覆盖较新的作者内容。

## 具体边界

点击后只安排一次动画帧回调，以选中后实际侧栏边界计算剩余画布宽度。只平移，不动画、不缩放以适配；大于可见区的节点只居中，不能保证全部显示。首尾帧审核浮层覆盖画布时仅打开对应角色，不在遮挡下移动底层视口。添加镜头、资产库等非既有节点目标继续原流程。

选择变化、卸载、画布重建、冲突重新载入、用户开始平移及任务／忙碌状态变化会使待执行定位失效。上述事件接线经过静态审查，不宣称已完成真实 DOM 事件验收。

## 验证与限制

新增 4 项纯变换回归：离屏居中且输入和缩放不变、可见／无效尺寸／缺失目标不移动、部分裁剪及大节点重复居中稳定、侧栏扣宽后的居中。全量 `npm test` 266/266（0 失败、0 跳过）、`npm run build`（含类型检查）及 `git diff --check` 通过。独立审查无阻断，前三项纯测试独立通过；最终四项及全量由主实现线程复跑。纯变换与事件边界测试只能证明计算及调用约束；实际 ReactFlow 视口、面板遮挡、滚动与 Windows 窗口行为仍需运行验收。
