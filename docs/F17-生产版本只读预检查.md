# F17 生产版本只读预检查

内部主进程函数直接查询现有 V7 工作区的 `tasks.revision` 和关联 `films`，不使用隔离原型的任务头。一次 SELECT 观察任务与版本，返回最高有效既有版本加一；没有记录时建议版本为1，版本存在间隙时不填补旧号。

只接受任务 UUID 与预期修订。任务缺失、修订已变化／异常、非正整数／超安全整数版本、重复版本、空记录ID以及成片对应执行不属于同任务均拒绝。SQLite 无法安全读取时返回固定错误，不透传路径或底层负载。

返回只包含任务、观察到的修订和建议版本，明确 `reserved=false`、`writeAuthorized=false`、`mediaVerified=false`。它不是预留，不分配版本，不查询文件，不证明媒体可读，不允许直接据此保存；未来写入事务必须重新检查并原子预留，不能消除预检查之后的竞态。

没有新增表、迁移、IPC或导入界面，不改变备份或恢复。两项合成测试使用真实 V7 临时 SQLite，其中只读连接验证重复读取稳定、所有表内容不变；异常记录使用测试库构造。没有真实用户数据或原生界面验收。

新增2项回归；全量320/320（0失败、0跳过）、类型检查、构建及差异检查通过。包括固定错误不泄露异常输入 getter 内容，V7 唯一约束拒绝重复合法版本；没有为制造重复记录篡改生产表结构。
