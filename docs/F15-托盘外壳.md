# F15 托盘外壳

V1.19 云端增量，基于178152a。仅实现桌面外壳，不包含定时触发、通知、入队、派发、补跑或任何外部调用。

## 行为

- 原生托盘成功创建且有效时，最小化隐藏原窗口；没有托盘时不隐藏，保留系统任务栏。内置图标随主进程打包，不依赖用户文件或下载。
- 菜单「打开主窗口」以及第二实例请求只恢复、显示、聚焦已有窗口，不重载渲染器，因此保留编辑与选中状态。若主窗已正常关闭但账号登录窗仍让应用存活，则受控重建主工作区（并发请求合并一次）；新窗口从持久化数据加载，不宣称恢复已关闭窗口的未保存状态。首次加载失败清理空窗，可重试。
- 「查看任务队列」恢复窗口并发送固定待处理意图；不直接路由、不清空草稿。主窗显示提示，由用户完成／关闭当前操作后明确打开队列。画布必须通过既有返回流程保存；任何打开的dialog、繁忙或未完成加载均阻止队列导航。可取消请求。
- 「退出」走应用原有退出路径，未保存内容仍可阻止关闭。点击窗口关闭按钮仍是原来的关闭／退出，不变成后台驻留。尝试退出不提前销毁会话、数据库或托盘，实际退出再一次性清理。
- 意图通道不接受任意路由、路径或命令，消费校验主窗口主frame；预加载仅暴露无参数订阅，取消订阅不泄露IPC事件。启动和重订阅期间的队列意图需保留。

## 验证边界

注入式生命周期、意图及导航保护测试验证程序状态转换，不等于 Electron／Windows 真实系统行为。当前云端未运行原生托盘或 Windows UI；此前 Chromium 因socket权限受限不能用于实际UI，本轮不触碰用户电脑。全量 `npm test` **132/132 通过，0 失败、0 跳过**；新增 7 项生命周期／异步订阅测试与 1 项显式导航门禁测试。覆盖托盘不可用回退、最小化恢复、退出否决后资源保留、可信消费与无参数限制、启动／退订重订阅缓冲、并发重建／失败重试／退出期间不显示，以及画布／dialog／繁忙／加载中的导航拒绝。`npm run build`（含类型检查）及差异检查通过。内置PNG经本地解码确认16×16 RGBA有效，不等于系统托盘显示验收。

## Windows 待验收

图标可见与菜单定位；最小化→托盘恢复、重复点击、第二实例；画布未保存／保存失败、计划或账号表单、备份进行中收到队列请求；退出被阻止后托盘／会话／数据库仍可继续使用；确认退出后无残留进程；托盘不可用时正常任务栏回退。需分别验证关闭按钮与托盘退出，不得把“隐藏窗口”当“自动保存成功”。

真实调度依赖F14等执行能力，托盘接入不会让尚未实现的队列开始运行。F15仍部分完成。
