# V1.19 离线制作链路验收

## 本轮性质

在独立云端工作区使用合成业务数据及合成 PNG，对生产应用服务、SQLite、图片归档、备份及隔离恢复作一次可重复的串联验证。不是原生界面冒烟测试，也不替代 PRD T01–T06 整体验收。

没有真实账号、浏览器会话、用户文件、外部生成服务或远端上传；没有新增产品规则、调度或自动提交。提示词由测试明确手写，不称为已接通自动生成。

## 串联范围

| 步骤 | 本轮证据边界 |
| --- | --- |
| 七天计划 | 通过生产命令创建计划及对应任务，保存计划风格 |
| 剧本与两镜头 | 逐步保存剧本、两个镜头及工作区内容 |
| 资产与关联 | 人物与场景跨镜头复用，明确采纳本地关联建议，再手动关联第二镜头道具；不是模型提取 |
| 提示词 | 手写镜头／视频／首帧／尾帧文本，保留输入快照及历史版本 |
| 两张静态图 | 合成 PNG 经实际解码归档，按首尾独立角色选择，通过专用确认命令 |
| 关闭与重开 | 关闭原数据库后重新创建应用服务，核对保存内容与确认快照 |
| V7 备份 | 生产备份服务生成业务库和静态图白名单包，验证清单及数据库版本 |
| 隔离恢复 | 只复制至全新隔离目录，不覆盖、不切换当前工作区；独立打开副本读回 |
| 一致性 | 对照任务、候选角色、确认输入、历史、图片及备份源完整性 |

## 执行结果

[test/offline-acceptance 场景](../tests/offline-acceptance.test.ts) 定向 **1/1**；全量 `npm test` **170/170**（0 失败、0 跳过），类型检查、生产构建及 `git diff --check` 通过。独立只读审查未发现阻断，文件链路测试由工程线程执行，审查者未独立运行文件测试。构建保留既有第三方 `use no memo` 非阻断警告。本轮仅新增测试与文档，没有修改生产规则或实现。

具体结果：
- 7 天／7 条任务、两次剧本保存／2 条历史、2 个镜头、3 项资产、5 条明确关联；5 类位置提示词产生合计 6 条历史版本。
- 两张颜色和比例不同的合成图经过真实解码归档，首尾角色与确认快照完整保留。
- 原数据库真正关闭，原图移走后重开应用服务，完整工作区内容一致。
- V7 备份含清单、业务库、2 张归档 PNG 共 4 个文件；验证结果为 7 任务／2 图。
- 恢复仅生成一个全新隔离目录，返回未激活工作区；独立打开副本后，完整工作区、每条剧本／提示词历史、审核快照及图片字节一致。
- 验证／恢复前后备份文件清单及 SHA-256 不变；恢复／读回前后关闭状态下的原工作区全部文件清单及 SHA-256 不变。账号、执行和成片记录为空，没有平台动作。

## 仍需真实环境验收

- **Windows 与原生 UI**：安装／升级、首次启动、原生文件选择与目录确认、画布编辑／焦点／滚动／弹窗、放大预览、真实关闭重启、托盘与未保存保护、用户可理解的失败恢复。
- **真实图片和运行约束**：Windows 实际路径及权限、磁盘空间不足、文件占用、操作系统休眠／退出、多进程压力；合成测试不能代表所有原生故障。
- **官方账号与能力**：两个账号登录隔离、会员与免费能力识别、支持的图片／比例／时长限制、首尾输入位、真实生成、状态跟踪、下载及官方免费无水印选项。
- **调度与恢复业务**：定时和手动派发门禁、重复提交防护、错过任务补跑、远端结果不明的核实与下载重试尚不能通过本轮离线链路宣告完成。
- **完整验收**：T01 的两风格真实生成、T02 的自动下游生成、T03 的首尾提交、T04 的会话能力、T05 的调度恢复、T06 的费用与成片均仍有未验收范围。整体模块状态不提升为完成。

备份完整性仅证明当前包结构与字节一致，不证明来源可信。恢复副本在测试中由独立服务读回，不代表产品已经支持直接切换并激活恢复工作区。
