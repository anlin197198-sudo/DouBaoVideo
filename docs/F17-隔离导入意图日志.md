# F17 隔离导入意图日志原型

只在调用方明确创建的独立测试数据库中提供 SQLite 日志，不改工作区数据库、不新增生产迁移、不接入本地导入按钮或生产端口。它验证持久操作身份与状态转换，不代表媒体已经导入或文件系统与 SQLite 已形成原子事务。

## 原型契约

- 日志只接受严格校验的本地操作标识、任务标识、预期字节摘要／大小及显式修订／版本条件。禁止额外字段，不保存源路径、视频字节、凭据或远端身份。
- 同请求、同规范化意图返回已有预留；改变任何绑定输入则拒绝，不能借重复请求覆盖旧意图。同任务未决操作保持排他。
- 主机显式提供任务修订／版本条件；这是测试日志的前置状态，不声称已经与真正工作区任务或成片版本分配同步。
- 发布前先持久标记“可能已发布”；首次转换返回 transitioned=true，重复返回 false，只能核实，不能当作再次发布许可。崩溃后不能从缺失成功回执推断未发布，更不能自动执行复制或发布。
- 最终确认只接受与原预留／字节绑定一致的封存回执，重复确认不能覆盖不同结果；事务只推进原型中的 nextVersion，不改变真实任务修订或完成状态。重开后只读核实原操作，不自动恢复任何副作用。
- 构造器核对独立库结构，不借用现有工作区。同 UUID 大小写统一为小写，规范序列化后比较完整输入，返回值冻结。

## 集成前仍需完成

当前原型没有真实文件或解码适配器，也不实际写入任务完成、执行或成片表。可信适配器仍须验证实际媒体、独占发布、持续排他并在承诺结束时停止全部后台工作。

生产接线必须统一设计数据库迁移、工作区状态与成片版本分配，以及 V7 备份／隔离恢复兼容。不能将此独立库塞进现有备份并冒称可恢复；当前备份不包含视频，恢复后的缺失媒体不应自动得到读取授权。未决预留如何人工终止、清理和重新开始也不由本原型擅自决定。

正常关闭／只读重开证明提交状态可恢复，不等于断电、损坏数据库或不同文件系统上的耐久性验收。宿主持有独立库的生命周期，原型没有更改 SQLite 运行安全设置。

## 本轮验证

新增4项回归，验证严格空库／元数据拒绝、规范请求幂等、修订与版本条件、两个独立连接的未决排他、可能发布状态的只读重开、回执丢失后的重复核实和封存不可覆盖。全量315/315（0失败、0跳过）、类型检查、构建、差异检查通过；双连接为顺序持久行为测试，不是多进程并发压力测试。独立审查无阻断，独立内存测试2/2通过。
