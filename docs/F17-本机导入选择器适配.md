# F17 本机导入选择器适配（主进程未启用）

新增真实 Electron API 的受信主进程适配器，调用 `dialog.showOpenDialog` 选择一个 MP4，再选择已有目录，最后用 `showMessageBox` 明确确认。本轮不注册 IPC、不添加按钮、不修改默认应用启动或目录设置。

源和目标只来自绑定发起 BrowserWindow 的本机对话框。源必须是普通单个 MP4，读取选择时文件身份供实际 intake 校验；不接受渲染器提供的文件路径。目录不启用自动创建选项，仍受主进程允许策略和既有目录身份校验约束。确认默认取消，显示任务、版本、字节数及目标，不能依靠 Enter 默认同意；不展示源文件路径。

适配器捕获真实发起窗口及 webContents 身份，结合宿主提供的文档代次和当前编辑器验证。关闭、主文档导航、崩溃、代次变化不能将旧选择继续用于新窗口或文档。独立解码使用真实 `createPrivateVideoFirstFrameHost`，其 owner 与发起窗口独立。

数据库、暂存根、构建资源目录、目标允许策略和当前编辑器验证均由可信主进程提供，不能成为渲染器参数或回调。适配器不注册全局 scheme 权限，不添加默认 handler；真实使用前还必须满足私有宿主的固定构建清单、独占会话和已授权 stream scheme 前置条件。
