# F02 末次复验回滚与重试回归

V1.19 云端增量，基于 ca79a7c。本轮仅验证既有隔离恢复服务，不扩大可信本地目标父目录的威胁模型，不修改生产行为。

## 已有保护与补充场景

既有回归已覆盖来源／目标／确认选择取消、复制前和输出验证取消、来源变化、输出损坏、受保护目录拒绝、可检测目录替换、V7 业务状态及旧版本保持。取消和失败不能激活恢复工作区或覆盖活动数据。

本轮补充组合场景：目标父目录已有一个成功隔离副本，新恢复在末次输出验证阶段取消或解码失败。必须只删除本次临时输出，保留已有成功副本、原 V7 备份及活动工作区主数据库／图片字节；失败释放实例锁后，同一服务能重新恢复到另一个独占子目录。

## 边界

使用临时合成目录、图片、数据库与会话哨兵，不读取真实用户文件。测试中触发 AbortSignal 属于内部服务取消，不表示原生对话框或运行中取消按钮已经验收。注入解码异常不等价于磁盘满、断电或 Windows 文件锁；这些仍需专门环境验收。

绝对路径 Node 文件 API 不提供对恶意同用户进程持续竞态的操作系统沙箱，本轮没有改变或扩张该既定契约。
