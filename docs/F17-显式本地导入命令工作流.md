# F17 显式本地导入命令工作流（主进程未启用）

本轮提供可组合的主进程工作流，不注册 IPC，不添加用户按钮，也不改变普通应用启动。既有只读 MP4 检查对话框保持只读，不能借此直接发布文件。

## 授权与生命周期

调用参数仅任务 ID 和预期修订，不接受渲染器文件路径。主进程宿主必须提供真实本机源 MP4 选择、目标目录选择和明确确认；目标选择不更改默认目录设置。数据库必须由宿主指定为当前应用拥有的 V7 工作区，而不是由调用者提供任意数据库或恢复副本。

整个流程冻结发起窗口／文档标识和代次；宿主 `isCurrent` 必须核对实际窗口对象、当前文档以及编辑器当前任务／修订（不能仅相信传入数字）。选择和确认期间取消、窗口关闭、换文档、任务变化均应阻止继续；同一工作流只允许一个请求。独立解码窗口使用自己的真实 owner，不冒充发起窗口。最终确认的任务、版本、文件摘要和目录由主进程封闭保存，旧确认不可用于新输入。

实际发布仍走既有暂存、正向首帧证据、撤销及确认探测停止、相同暂存字节独占写入、物理复核和 V7 事务路径。不能把异步取消作为“写入没有发生”的证明，必须等待副作用收敛后返回实际归档／记录事实。已发布文件不因取消或数据库失败被删除。对外结果固定且脱敏，不返回源／目标路径、令牌、数据库异常或媒体内容。

## 验收边界

本轮仅使用合成 MP4、临时目录、真实 SQLite／独占文件写入和模拟原生探测宿主验证组合。未执行 Windows／Electron 原生窗口、选择器或解码；原生选择器适配、用户体验和默认应用接线须在原生验收后另行启用。首帧证据不是全片解码证明，登记元数据不是播放权限。

独立本地附件保留任务状态和本地来源；PRD RUN 02 已有远程执行的待下载恢复仍需原执行及同一远程输出验证，不能借本工作流生成新执行替代它。

## 当前验证与宿主契约

目标目录在确认前后及后续同步发布门控中核对规范路径、非符号链接目录及原 dev/ino，同时重新检查宿主允许策略。这是受信本地目录防误换检查，不声称抵御任意同用户攻击、文件系统 inode 重用或所有 Windows reparse 类型。宿主还须为原生选择／确认端口提供真正绑定该发起窗口的对话框，不得把端口作为渲染器回调暴露。

停止补偿最多等待 1000ms；未确认停止时返回 cleanup-unconfirmed、保留暂存，不强行删除原生读者可能仍使用的文件。这个上限不用于抢先结束归档或数据库副作用；命令须等实际副作用结算。`settled` 不是成功的同义词，调用者必须分别读取 archiveStatus、recordStatus、cleanupConfirmed；未知发布不会降为 none，晚窗口失效不会抹掉已发布事实。每次重新确认形成新的明确导入动作，不提供自动重试。

验证：新增 6 项合成集成回归覆盖实际文件／事务与脱敏结果、取消／拒绝／修订变化／目录策略撤销、发布后窗口失效、并发与任意路径字段拒绝、停止永不结算、探测期间目录替换。`npm test` 427/427（0 失败、0 跳过），`npm run build`（含类型检查）和 `git diff --check` 通过。未运行原生选择器或 Electron。
