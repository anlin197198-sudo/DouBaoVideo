# F07／F10 长分镜合成序列回归

V1.19 云端增量，基于 2fc25e0。仅使用程序生成的 48 镜头良性测试文本、注入的内存规划器和独立 SQLite；不读取用户剧本，不调用真实模型、网络或密钥。

## 验证目标

合成候选经过当前结构校验、明确采用和正常保存，验证 48 个镜头的顺序／身份及字段不被截断。交替关联的资产仅进入相应镜头的固定格式内容，保存提示词后关闭数据库重开，检查完整文字、顺序、只读汇总和历史仍一致。

异常分支验证截断 JSON、超过候选长度上限及超过镜头数量上限不能成为可采用候选，也不写入工作区。不是用截断前缀凑出一个“看似成功”的候选。

## 限额不能混为一谈

- 离线候选原文上限是 2 × 1024 × 1024 个 JavaScript UTF-16 code units，镜头数量上限200，另有逐字段长度约束。
- 真实规划客户端输入 system + user 上限128KiB UTF-8字节，响应上限2MiB字节，输出请求上限8192 tokens。现有客户端回归拒绝 finish_reason=length 的截断结果，不以语法可解析当作模型完整结束。
- 48镜头合成数据通过只证明该具体夹具在本地契约／存储／格式器中的完整性，不证明真实模型能在8192 tokens内输出同等内容，不代表所有最大长度字段组合都可用，也不是性能或实际画布验收。
