# F17 离线成片命名边界

V1.19 云端增量，基于 f44a941。依据 F17 的 Windows 非法字符／保留名称处理，以及同名任务、新执行和新版本不能互相覆盖的要求。本轮仅生成受限的文件基本名，不创建文件或成片记录。

## 身份与显示文字

文件名保留完整任务 UUID、完整执行 UUID 和明确版本号作为区分身份。标题只供辨认，不作为唯一键；不同标题清理成同样文字时，不同身份仍生成不同文件名。相同有效输入得到相同结果，不用当前时间或随机数。

固定格式为“安全标题--任务UUID--执行UUID--v版本.mp4”。标题输入最多2000个UTF-16单位，空标题或清理后仅剩点／下划线时回退video；输出基本名最多240个UTF-16单位，按码点截断，不拆开有效代理对，孤立代理项替换。UUID统一小写，标题NFKC规范化。输入严格限制字段及类型；身份非法、版本不合法或标题超界即拒绝，不默默截断身份。标题部分处理 Windows 路径分隔符、非法／控制字符、保留名称和尾部空格句点，并限制长度，不能通过标题注入目录、盘符或备用数据流。

## 不代表已经保存成功

- 这是基本名，不接受保存目录，不证明目标文件系统可写，也不验证完整路径长度。
- 后缀仅是当前命名约定，不证明字节是有效视频或媒体类型已核实。
- 相同身份重复调用会得到同一个名称。未来保存端必须独占创建并核实目标冲突，不能直接覆盖；本函数不做文件预留、原子写入、并发控制或唯一数据库约束。
- UUID只是调用方传入的标识，函数不证明执行归属该任务；未来应用层必须核实归属及版本分配。
- 没有下载、导入、暂存文件、播放器、真实执行／成片版本管理或Windows运行验收。F17真实业务验收保持未完成。
