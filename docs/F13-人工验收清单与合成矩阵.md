基线 e90e22e，V1.19。本轮只补合成回归和操作者清单，无产品接线或真实服务测试。

## 当前阻塞，不可跳过

真实豆包入口、登录／免费状态和同模式能力尚未核实；没有生产能力证据适配器、真实提交器或结果核实流程。F13 内部预检仅返回 `preflight-only / submitted:false`。附加素材仅有本地草稿确认边界，尚未进入产品提交预检。没有持久执行尝试、幂等发送、冲突回执裁决及超时查询恢复。因此当前不能做真实端到端视频验收，也不能以本清单授权账号操作或上传。

## 后续操作者最小清单（均未执行）

1. **确认范围**：在获准的测试账号和合成素材下明确本次验证内容。记录官方入口、观察时间、平台显示的实际模式和限制；页面没有显示就标“未核实”，不要猜测按钮或功能。
2. **登录与费用**：实际核实该账号当前登录与所选生成操作是否免费。账号资料的手动标记、会员档位和本地复制成功不能代替证据。费用未知、需要付费或额度不明即停止，不尝试绕过。
3. **同模式能力**：核实同一入口是否同时支持首／尾两个角色、计划比例和时长。只支持其中一个角色或模式不一致即阻断；同一图片用于两角色不等于提供方允许，须分别验证其规则。
4. **封存输入**：确认保存修订、准确视频原文、首尾候选身份及图片字节摘要仍一致。不能用未保存草稿、加载预览或手填 @图片N 替代主进程校验；任何替换／损坏／输入变化需重新审核。
5. **附加素材**：逐项确认必需素材是否明确选择且该模式真实支持其类型／角色／数量。缺少必需素材不得静默删掉后发送；当前附加素材预检仍阻断，须先实现完整接线。
6. **单次尝试**：未来提交前记录同一 attempt、账号、任务、输入修订及快照摘要。现阶段没有该持久化发送实现，不得用本地分类函数当作已发出任务。
7. **回执**：只有可信适配器验证并绑定本次尝试的外部任务引用才可记为已受理，仍不是视频完成。明确证明远端没有建任务才归类拒绝；超时、断连、空回执或错账号／错尝试都必须核实，不盲目重试。
8. **迟到与冲突**：超时后收到回执仍需按同一尝试核实；冲突证据不能采用“最后一条覆盖”。没有可靠查询／裁决能力就保留待核实，不能自动新建尝试。记录失败阶段和下一步，勿记录凭据、会话或原素材内容。

## 可重复合成矩阵

所有案例仅用合成 SQLite、图片和注入证据，不登录、上传或调用提供方。运行：

```sh
node --import tsx --test tests/video-preflight.test.ts tests/extra-asset-draft.test.ts tests/submission-result.test.ts
```

| 条件 | 预期 | 现有/新增覆盖 |
| --- | --- | --- |
| 当前登录、免费证据缺失／过期／未知／付费 | 阻断，手动账号可用标记不改变结果 | video-preflight |
| first/last 完整两角色、合法当前参数 | 仅本地预检，输出顺序固定首→尾，仍不提交 | video-preflight |
| 缺角色、重复首、重复尾 | UNSUPPORTED_INPUT | 新增操作者矩阵 |
| 第三／未知角色、未经契约确认的 mode 字段 | CAPABILITY_UNVERIFIED，不接受额外声明 | 新增操作者矩阵 |
| 缺必需附加素材、仅选择、选择且声明必需 | 当前全部 EXTRA_ASSETS_UNCONFIRMED | 新增操作者矩阵 |
| 附加素材同模式、类型／数量、当前内容摘要 | 仅本地确认；不表示进入提交预检 | extra-asset-draft |
| 图片损坏／归属变化／修订陈旧／确认失效 | 阻断；修复字节仍需当前证据 | video-preflight |
| 同 attempt 超时、明确受理、错 attempt、明确未建任务、迟到空值 | 独立分类，全都 unconditionalRetry:false，受理不等于完成 | 新增同尝试分类回归 |

“独立分类”不是持久恢复状态机：前一分类对象保持不变，不保存状态、不裁决矛盾回执、不发出任何重试。
