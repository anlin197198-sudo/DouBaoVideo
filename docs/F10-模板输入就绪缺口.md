# F10 模板输入就绪缺口

## 为什么没有一键填入

当前 `PromptTemplatePreview` 调用格式化器时不传扩展字段。无论现有镜头、人物、场景或风格备注多详细，基调、光线、色彩等独立模板字段仍显示「未提供」；动态镜头还缺逐镜头时长和连续性，静态首尾图缺各自独立构图与状态。

因此不能把固定格式预览当成完整提示词填进空槽，更不能自动保存、核对或确认。当前只读预览补充了未提供独立录入方式的字段说明，复制和人工编辑路径保持不变。没有新增采用按钮、变更原提示词／历史、调用模型或推断用户没给出的内容。

## 缺口说明而非提供方规则

新增纯函数说明当前 UI 输入模型的缺口：区分「没有独立字段」与「已有字段为空」，按所选镜头或首尾端点限定范围。`canFill: false` 仅描述当前固定预览无法完整自动填入，不是通用安全权限或提供方校验，也不阻止用户手动编写提示词。

已有字段为空只供人工检查。例如没有人物或声音可能是有意选择，不因此发明提供方必填规则。UI 只列未提供录入方式的字段；不会根据总片长均分镜头时间，不把动态动作转译成静态构图，也不复制范例中的设备、角色或场景。静态缺口不列动态时长／音频要求。

## 后续
