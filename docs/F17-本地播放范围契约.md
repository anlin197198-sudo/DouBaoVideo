# F17 本地播放范围契约（未接入播放器）

新增可独立测试的本地视频读取响应及单段字节范围计算。它不接注册、文件系统、Electron 协议或界面，不从现有成片路径直接打开文件。

- 只为规范形式的 `app://video/<小写UUID>` 接受 GET、HEAD，经注入的主进程查询解析显式获准的来源。普通本机路径、外链、附加查询、片段、用户名、端口和额外路径均不在契约内。
- 只允许注入已验证媒体的受信来源。整段 GET 返回 200；单段 GET 返回 206、精确长度及范围；不合法或不支持的多段请求返回 416、不打开流。HEAD 不创建响应正文流（新文件适配器获取时仍读取文件校验摘要）。响应不缓存、不暴露磁盘路径。
- 不取流时关闭来源，取得流后所有权移交，由读流层在读完、取消或错误时关闭同一已验证句柄。正式接线前必须补齐此层的资源生命周期测试。
- 原有成片表没有已验证媒体注册记录，备份不包含视频文件。下一步先建设验证后登记的应用受管副本；仅外部路径、旧成片元数据或缺失文件不能获得读取授权。接入播放器后再以合成视频验证播放及进度跳转，Windows 原生验收单独记录。

五项自动测试使用合成字节和注入来源，覆盖单段范围、错误、只读取注册键、HEAD 不读流及取消转交。不代表视频已在应用或 Windows 上播放。

后续增加了休眠的[登记文件读取适配器](F17-登记文件读取适配器.md)，以主进程显式清单和固定句柄完成合成文件校验／范围读取；尚未连接产品登记或协议。以上注入层历史测试不等于文件适配器或 Windows 播放验收。
