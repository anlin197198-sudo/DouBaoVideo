# F10 临时全片字段预览

固定格式预览新增明确的三个临时输入：影片基调、光线设计、色彩锚点。仅使用用户填写的原文，不从剧本、风格备注、范例或其他提示词推断。每项最多 2000 字符；空白仍按缺项处理。

## 生命周期

输入只存在当前提示词位置的预览组件内存。同一预览重新渲染或收起 `details` 不清空；「清空临时字段」只清空这三个输入。关闭提示词面板、切换任务或提示词位置后组件卸载，临时字段清空。界面明确告知这一点，不假装已经保存。

预览正文依旧只读；用户可明确复制，再到原提示词编辑区人工完善。没有自动填入、保存、核对或确认。复制进行时暂时禁用临时输入；既有迟到结果保护继续核对当前预览正文，避免变化后误报复制了新内容。

## 兼容与限制

没有工作区模型或数据库变更，没有新增持久化／备份文件，旧工作区和 V7 备份结构保持原样。这里不是模型输出或真实提供方能力。已输入的三个字段从当前缺项说明中消失，但逐镜头时长／连续性、参考图上传对应及静态端点构图／状态仍不能凭空补齐，`canFill` 仍为 false。

文字字段不执行代码或外部调用，React 按普通文本显示。静态图继续只使用各自端点，不复制动态动作或运镜时间。DeepSeek 不参与；没有真实账户、媒体传输或提交。

新增 3 项合成测试，全量 `npm test` 225/225（0 失败、0 跳过）、类型检查、生产构建和 `git diff --check` 通过。独立复审无阻断且定向 3/3 通过。测试覆盖严格字段／长度／原文保留／空白及清空、缺项过滤，以及四种提示词输出和静态动态隔离。真实 UI 生命周期、剪贴板与 Windows 尚未运行验收；既有第三方 `use no memo` 构建警告非阻断。
