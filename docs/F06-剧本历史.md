# F06 已保存剧本历史

V1.19 云端增量，基于 c532591；只覆盖本地手动正文历史，不涉及真实生成、候选、对比或恢复。

## 数据与迁移

数据库 V6 增加 script_history，按任务和版本唯一，正文、记录时间与 baseline/saved 类型不可变；新表限定正整数版本、文本类型及10万字上限。禁止 UPDATE／DELETE 的数据库触发器保护历史。V5→V6 迁移只读取当时存在的当前正文，每个已有任务记录 v1 基线（可能为空）。基线时间是首次记录时间，并非原始创作时间，不能恢复此前未记录的编辑。迁移失败回滚本次版本，不覆盖旧正文。

新建任务初始空稿不虚构保存历史；第一次实际正文变化记 v1。之后只有正文精确变化才追加，包括清空与空白变化。布局、其他内容保存和无变化正文不重复增版；保存／版本冲突、回执幂等和历史追加共同使用原事务边界。历史独立于当前 workspace JSON，避免每次编辑携带所有旧稿。

## 查看

在剧本编辑区点「查看已保存剧本历史（只读）」。列表按版本倒序，每页20条（接口最多30）；只载入版本、时间和长度，点击才读取正文，空正文版本明确显示。列表和详情读取具有独立的请求序号，自动保存刷新列表不打断正在查看的不可变详情；关闭／切任务后迟到结果不应用。无恢复按钮，不改变草稿或依赖状态。

接口严格按任务限定并校验输入和可信发送者，读取不创建写入回执。历史包含业务正文，纳入本机业务备份，仍应妥善保管。备份校验采用受信任 V6 schema，并保持 V3／V4／V5 验证和隔离复制，不执行备份自身提供的 DDL，也不原地升级备份源。可信 schema、文件完整性和现有任务／图片引用检查不等于所有历史记录的时间、内容语义或与当前正文一致性均已验证。
