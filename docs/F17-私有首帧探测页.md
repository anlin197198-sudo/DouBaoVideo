# F17 私有首帧探测页（生产构建分片，未接宿主）

基线 `bffedd2`。Vite 仍构建正常 `out/renderer/index.html`；另外构建 `out/renderer/f17-video-probe.html` 及其页面内引用的同源哈希 JS，不在主界面加载该 JS，不启用私有协议路由、媒体登记、原生窗口或任何公共 IPC。

- 页面只在精确的 `app://video-probe/f17-video-probe.html#<小写 UUID>` 上开始一次探测。只读原始 fragment，拒绝编码变体、查询、额外路径、非预期主机或重复调用。能力只派生为 `app://video/<UUID>`；不可传入外链、文件路径或数据 URL。页面不会读取本机文件，也不会调用 fetch。默认 renderer 即使以通用静态路径读到该分片，其 `app://renderer` 地址也无法启动播放；真正的私有主机仍未绑定。
- CSP 默认拒绝，仅允许同源模块脚本、`app://video` 媒体；显式拒绝连接、表单、嵌套页面、工作线程、对象、base URI。不使用 Node、preload 或公共 IPC。未来专用宿主必须只允许固定 HTML 与构建生成的精确哈希模块路径，不靠 CSP 或 UUID 自证窗口／文档身份；禁止非预期导航、弹窗或外链。
- 结果只通过专用窗口自己的不可枚举、不可改写、不可重新定义的 `window.__doubaoF17ProbeResult` 读取。初始不存在；通过时仅固定状态及有限数字帧证据，失败只返回有限的固定失败码。无 token、路径、回复或异常字符串。布局不可见；`pagehide`、片段改变、探测超时会停止，导航离开的结果不发布。主进程必须独立持有窗口与当前文档身份、设定有界等待、重新校验输出，绝不能把该属性视为身份或完整性证明。
- 通过仅表示首个合格画面被观察到，不是整文件解码、拖动、音频或正式成片验收。尚未运行原生 Windows、Electron 或真实媒体；自动测试用注入对象与构建审查，不等于原生路径成立。
