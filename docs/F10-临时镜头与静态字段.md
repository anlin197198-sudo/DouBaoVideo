# F10 临时镜头与静态端点字段

在当前提示词位置的格式预览中，镜头类型可明确输入时长或时间说明、连续性约束；首帧和尾帧类型分别可输入静态构图及起始／结束静态状态。每个位置只显示两个字段，每项最多 2000 字符，不新增大表单。

## 作用范围

所有输入仅更新当前只读格式预览。按原文使用时间说明，不解析成总时长、不分摊秒数、不从动作猜端点姿态。空字段仍为未提供；静态首尾字段彼此独立，不混入镜头动作、运镜时间或声音。

同一位置重新渲染、收起预览保留输入；切换提示词位置、任务、关闭面板或首尾实际端点镜头改变后清空。端点改变时包括三个临时全局字段也重新开始，避免旧上下文混入新端点。「清空当前位置临时字段」只清空这两个字段，不动正式内容；原全片字段清空只影响基调／光线／色彩。

整条视频预览暂不收集其他位置的临时输入，也不自动合并它们。用户可分别复制并人工整理。没有一键采用、保存、核对、确认或发送；临时输入不写工作区或数据库，不改变旧备份结构。

## 缺项提示与后续

仅移除当前明确填写且身份匹配的字段缺项。即使显示的结构化缺项都有临时输入，仍明确要求人工核对，`canFill` 不成为可用动作。提供方的角色、时长、数量及免费能力仍未验证。

本轮没有外部模型、DeepSeek、用户稿件或 Windows 操作。持久化作者输入、整条视频汇总临时值、实际 UI／剪贴板与桌面验收仍待后续明确实施。

新增 3 项合成测试，全量 `npm test` 228/228（0 失败、0 跳过）、类型检查、生产构建和 `git diff --check` 通过。独立复审无阻断且定向 3/3 通过。测试覆盖显式原文、空白、字段／长度边界、镜头与首尾身份隔离、重排／端点变化、静态不含动态内容及缺项过滤。实际 UI 清空／切换和剪贴板、Windows 未运行验收；既有第三方 `use no memo` 构建警告非阻断。
