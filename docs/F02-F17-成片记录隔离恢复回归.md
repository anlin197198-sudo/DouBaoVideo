# F02／F17 成片记录隔离恢复回归

本轮仅补跨模块合成测试，不修改数据库结构、备份格式、恢复实现或产品操作。

## 锁定边界

- 在真实 V7 临时工作区中建立合成任务、执行、成片记录，并放入实际合成归档字节。它们不代表可播放视频。
- 通过真实备份、只读验证与隔离恢复流程保留成片元数据，但备份和恢复目录不包含视频文件或视频读取授权。
- 恢复后本地成片列表只能显示记录；生产快照与静态渲染不输出旧源路径，并明确文件可读性／媒体有效性未验证。
- 即使原工作区文件仍然存在，恢复成片记录也不会成为显式登记。使用空登记清单的读取响应仍为404，不回退读取历史路径。
- 隔离恢复不激活工作区、不派发任务。原工作区业务记录和合成视频字节不变，原备份内容不变。

## 不作出的承诺

这是 V7 现有边界的回归，不是 V8 的恢复来源标记、凭据撤销或权限隔离设计。数据库可能保留历史路径作为业务记录，但 renderer 快照不输出它；元数据恢复与媒体可用性是两回事。

不证明真实视频解码、播放器、原生 Windows 操作或重新启动整个应用的调度行为。恢复服务自身不创建执行入口；原执行记录保留原状态，不声称通过修改历史状态阻止未来尚未实现的执行器。
