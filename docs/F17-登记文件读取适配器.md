# F17 登记文件读取适配器（内部休眠）

为既有 `RegisteredVideoSource` 增加主进程文件适配器，但没有接入 Electron 协议、播放器、下载或数据库登记。仅接受调用方显式提供、已验证媒体的登记清单；这里的字节完整性校验不等于 MP4 解码或媒体有效性认证。

## 授权与读取边界

- 只使用规范小写 UUID 查询主进程清单。没有登记的键返回不可用，不查询旧 `films.file_path`，不接受请求中的路径。
- 从受信登记的任务／执行／版本／标题通过既有命名器计算基本名，限定在应用受管、规范化的普通根目录内。清单复制后使用，外部修改不会改变已建立的授权。
- 检查根目录及文件身份、普通文件、单硬链接、预期正整数大小及上限；拒绝缺失、符号链接、路径解析不一致和身份不符。
- 获取时固定文件句柄，以最多 64 KiB 缓冲读取全文件并核对已登记 SHA-256；大小相同但内容改变也拒绝。每次获取重新计算，代价为 O(文件大小)，不是秒开性能承诺。HEAD 虽然不打开响应流，也会先完成获取校验。
- 同一句柄只移交一次给精确起止范围读取；读取、取消、错误及未取流显式关闭均释放资源。不会为范围请求先缓存整个视频。

## 保留限制

根目录和登记由可信主进程管理。这不是防御恶意同用户持续替换目录或原地写入的操作系统沙箱；验证后仍需应用维护副本不可变。通用 Node 的 lstat／realpath 检查可以拒绝其识别的链接及路径重定向，但不能证明拒绝 Windows 所有特殊 reparse 类型。正式 Windows 接线前须补充原生文件类型／重解析点策略和验收，不能据此宣称 Windows 安全播放已完成。

没有持久登记、备份／迁移、协议接线、媒体解码、播放器或 UI。临时合成字节的范围读取与关闭测试不是实际视频播放验收。

本切片新增4项临时合成文件回归，覆盖登记清单复制／私有键、范围读取、关闭／取消、同大小篡改、身份与大小不符、链接和非规范根目录拒绝；全量303/303（0失败、0跳过）、类型检查、构建及差异检查通过。没有 Windows、媒体解码或播放器运行验收。

组合回归使用隔离合成字节，从独占写入到登记再到单段读取；同任务重做版本独立保留，重复写入拒绝，未登记的新版本不能经响应读取，旧版本字节完整。此验证不进行视频解码或真实媒体播放。

### 真实格式的合成文件验证

已在 Linux 云端执行 `node --import tsx scripts/local-film-smoke.ts`。该可选烟测要求本机已有 ffmpeg（含 libx264）与 ffprobe；不安装或打包依赖、不接收外部路径或用户文件。它在隔离临时目录合成 160×90、12 帧 H.264 MP4，经现有独占写入和登记读取检查整文件及末段字节，独立核对媒体元数据并解码全部帧，结束删除本次合成文件。此测试仅证明云端合成 MP4 样本保持可解码，未运行应用播放器或 Windows。
