# F10 从已保存分镜填入视频草稿

在整条视频的镜头汇总下先打开可编辑的本地预览。初稿按叙事顺序拼接当前已保存镜头提示词原文（镜头间用空行分隔），不加入状态标签，不推断运镜、动作或转场。预览、修改预览或取消均不保存。明确点击「仅填入空白视频提示词」才交给现有自动保存。

没有镜头，镜头文字缺失或旧输入未核对，或草稿超出十万字符时不可预览填入。任务切换、输入／修订改变，以及保存中、失败或冲突会废止预览。画布使用即时控制器内容再校验，不信任失效的预览回调。已有目标文字，包括手填空白字符，不被覆盖；存在但仍引用旧输入的空记录也需先核对。只编辑整条视频提示词，不改首尾帧提示词、镜头、资产或历史。填入不代表保存成功，不自动核对或提交。

合成自动测试覆盖逐镜头原文顺序、明确写入与重复阻断、占用及旧输入、长度限制、保存失败保留草稿／重试及 SQLite 重开。Windows 桌面、安装包和真实模型不包含在内。
