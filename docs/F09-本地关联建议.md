# F09 已有资产本地关联建议

V1.19 云端增量，基于集成检查点 a46daef。依据 PRD CAN 02「可采用软件推荐的连线」实施已有内容的辅助规则；不替代界面文档中从提取结果一次「采用资产与关联」的完整流程。

## 使用与边界

1. 选择镜头，进入「关联资产」，点「预览本地关联建议」。
2. 仅匹配已有资产名与当前镜头标题／画面／动作，显示实际匹配字段和片段，默认全部不勾选。
3. 核对后勾选所需项，点「采用勾选关联」。只增补连线，不删除现有连线、不改正文或新增资产。由既有自动保存写入，可查看保存状态；采用不等于保存成功。
4. 关闭／刷新不更改工作区。修改镜头、资产或手动关联后旧预览拒绝采用，需刷新重选。纯位置、视图或审核旗标变化不作内容变化。

匹配采用 Unicode NFKC、大小写和连续空白归一；空名称、单字、默认未命名、仅符号及歧义同名不推荐，Latin 名称检查词边界。已有连线不重复建议。规则不理解否定、别名、代词或场景隐喻，例如“没有雨伞”也可能命中雨伞，必须人工审核。匹配片段为归一化文字，不是外部模型的判断。

预览不持久化，不增加 IPC、数据库表或外部调用。采用重新计算有效候选，先校验全部选择，再通过现有 setAssetLink 追加；资产核对、提示词失效与图片确认失效沿用现有编辑／保存链路。真实提取、新资产与建议联合采用仍待实现，不宣称 F09 整模块完成。
