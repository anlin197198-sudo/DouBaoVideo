# F17：成片页本地导入界面门控

成片页可以接收显式注入的可信本地导入能力。只有注入存在才显示入口；标准应用没有注入，成片页仍仅显示本地记录。本轮不增加 IPC、文件选择／保存协议、远程功能或播放器。

界面绑定当前任务 ID 与保存修订，处理期间锁定入口以防重复点击。点击只请求选择本地 MP4；文件和目录由原生入口选择，并在写入前另行确认。界面只显示主进程返回的有限状态，不显示本地路径、原始异常或远程身份，不自动重试。已有登记触发记录刷新；若文件已保存但登记未确认，则要求先核对。不将已登记理解为可播放。

任务、修订、能力或页面变化时放弃已离开范围的回复，提供取消信号但不保证中止既有写入，也不显示“未保存”。再次打开应读取当前记录。注入端应保持引用稳定、尊重取消信号，并在应用刷新结果前检查信号；主进程仍负责最终写入防护和全局活动锁。

使用合成任务、状态及回调测试。未运行 Windows、真实素材、提供方或原生文件对话框。
