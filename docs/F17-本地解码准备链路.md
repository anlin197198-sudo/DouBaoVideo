# F17：本地解码准备链路

此内部主进程协调器把一次已接收的 MP4 输入，通过[真实暂存器](F17-MP4-本地暂存.md)保存为已校验的临时字节，再利用[临时播放探测登记](F17-临时播放探测能力.md)授权独立探测文档读取。只有可信宿主获得临时 URL、已绑定的窗口／文档身份及取消信号；沙箱文档只需 URL 和取消机制，不拿到文件路径、摘要、字节接口或业务数据。

主进程要求该临时 URL 首先取得与暂存摘要相符的字节来源，再接受严格校验的首帧事实。仅加载元数据、无读取、畸形、超时、令牌撤销或所有者变化后的结果都不算通过。通过只证明受信宿主观察到一帧，并与暂存文件的长度及 SHA-256 绑定，不等于全片解码、成片播放、发布或完成。宿主必须在取消时关闭独立文档，不得擅自声明成功。

每次退出都撤销能力，通知宿主停止并清理已知暂存句柄／文件和源读取句柄。超时或取消不等无响应的宿主；迟到结果无法被采用。临时文件清理或输入关闭不确定时，只报告固定未确认状态，不泄露路径或原始异常，也不输出通过证据。

验证使用合成 MP4 字节贯通本地文件、暂存和登记端点，宿主首帧反馈为测试替身。未接 Electron 原生隔离协议、产品入口、数据库或发布；未运行 Windows、真实媒体或 API。

## 可选的同一快照移交

主进程可在调用时提供消费回调及独立的编辑任务有效性检查。它必须配置可信原生停止确认：先验收首帧、撤销临时 URL，等原生停止明确确认，再把同一份暂存数据的一次性只读访问器交给可信回调。回调只得到摘要、大小和有边界的完整字节流，不得到文件路径、原生返回或渲染身份。重新获取时再次验证文件身份及内容；到达准确字节结束前，不能把回调返回视作成功。

取消、任务失效、异常、读取不完整或第二次尝试打开不转移所有权；该访问器在回调结束后失效。只有明确结束的快照才根据原有身份安全清理；无法确认原生停止或文件身份时保留并报告不确定，不扫描旧文件。宿主应在任务失效时触发取消信号，避免等无响应的可信回调。此移交只支持读取和检查，不实现归档发布、全片解码、数据库、生产播放或 Windows 原生验收。
