# F10 已保存镜头提示词汇总

整条视频预览新增独立只读汇总，按当前镜头叙事顺序列出已保存、依赖仍有效的镜头提示词原文及版本。原固定模板不被替换，已有手写视频提示词和历史不改变；仅可明确复制汇总，不生成或写入整条视频提示词。

## 来源与有效性

保存状态和修订来自现有自动保存控制器。脏稿、保存中、失败或冲突时隐藏全部已保存镜头正文，避免把本地草稿当成保存结果。该视图不是单独查询数据库的快照，不是提交校验。

只在镜头提示词非空，且 `inputSnapshot` 与当前该镜头 `promptInput` 精确一致时列出原文。缺少文字标为缺失，输入不一致标为待核对，不包含旧正文；不会通过读取历史补齐，也不自动执行核对。正文里的措辞保持原样，不补连续性、动作或提供方要求。

镜头顺序、剧本、有效风格和实际关联资产变化会按既有依赖规则影响有效性。重排后必须重新核对，不能只把旧文字换序就称当前有效。未关联资产不加入汇总，不自动引入其他任务或位置的临时字段。

## 复制与边界

汇总是带状态标签的检查材料，不是已经生成好的出片提示词。缺失或待核对项明确保留，不能把它们静默跳过后冒充全片完整。复制仅用户显式触发；来源变化或关闭后，迟到结果不误报为当前内容复制成功。

无数据模型、数据库、备份或历史更改。整条视频仍不开放自动填入／确认／提交；不调用 DeepSeek、外部服务或用户样稿。实际 UI 和 Windows 验收需另行执行。
