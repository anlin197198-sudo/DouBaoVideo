# F17 原生首帧独立烟测（开发者显式启用）

## 目的与边界

提供真正调用 Electron 专属窗口、协议及首帧宿主的独立入口，而不是再增加一个模拟播放器。它不被普通应用启动引用，不添加导入按钮或默认会话 handler，不接受用户素材、路径、账号或服务参数。

唯一素材是仓库内 1923 字节的合成 H.264 MP4：本机 FFmpeg 从 160×90 的纯蓝色画面生成，12fps、1 秒，无音频／人物／用户材料。入口校验其固定 SHA-256，随后实际使用 intake、暂存、私有窗口与固定页面进行首帧探测。文件结构检查本身仍不等于解码成功。

## 未来在获准 Windows 环境执行

要求该开发检出已经具有可信的本项目依赖及 Windows Electron 运行时。此流程不下载或安装运行时，不回退到 PATH 中的其他程序。

```powershell
npm run build:f17:native-smoke
npm run smoke:f17:native -- --run
```

除下述明确的完整导入模式外，没有 `--run`、附带其他参数或非 Windows 系统均不会启动 Electron。不要添加 `--no-sandbox` 或权限绕过参数。不要用普通安装版 EXE 替代项目运行时；本入口不是安装包验收。

构建产物位于忽略提交的 `.local/f17-native-smoke`，与普通 `out/main`、`out/renderer` 分离，避免污染正式打包文件及哈希审计。该独立入口不会自动运行 `npm install`。

## 隔离与输出

启动器只调用固定的已安装 `node_modules/electron/dist/electron.exe`，子进程环境采用白名单。HOME／USERPROFILE、APPDATA、LOCALAPPDATA、TEMP／TMP 指向本次新建的私有根；不传递 API key、代理、Node 注入或 provider flags。独立主进程在 app ready 前再建立自己的 userData、sessionData、日志和 crashDumps 子目录。

只在这个独立进程注册 `app` 的 standard、secure、supportFetchAPI 和 stream 权限，不设 bypassCSP。宿主创建独占内存会话，页面资源受固定构建清单及 CSP 约束。

输出仅包含固定 stage/result，以及成功时的宽高数字。原生 stderr 不转发，其他 stdout 不转发，路径、令牌、异常及未知字段均不输出。主进程非零退出不会被保留成成功报告。

主进程限时 15 秒；启动器 20 秒超时后只尝试结束自己启动的直接子进程，捕获失败、解除自己的等待并报告 timeout，不声称整个进程树已经退出。正常宿主清理仍须确认窗口／路由停止，才能移除暂存。烟测私有根始终保留，因为主进程退出不单独证明所有 Chromium 子进程已静默；之后由操作者确认测试进程已停止，再清理仅本次 `dvb-native-probe-launch-*` 目录。不要清理应用默认数据目录。

## 新增：合成完整导入模式（仍须未来授权后原生执行）

```powershell
npm run build:f17:native-smoke
npm run smoke:f17:native -- --run --full-import
```

保留原来的 `--run` 首帧模式。新模式必须按上述顺序同时提供两个参数；重复参数、额外参数以及任何源文件／目标目录参数均被拒绝。仍只使用同一仓库合成样本，不接受用户视频，不启用普通应用的导入入口。

完整模式在此次新建私有根内创建真实 V7 SQLite 工作区和一个合成任务，使用实际专属 Electron 首帧宿主，再调用既有组合服务：暂存、同字节正向首帧证据、撤销令牌并确认宿主关闭、独占写入、物理复核、事务登记。随后关闭并重新打开数据库，逐项核对任务整行未变化、唯一中性 `local-import` 执行（无账号／远程引用）、成片版本及命令回执。归档必须与原合成字节完全一致，源文件不变、暂存已清空。重开仅做读回，不恢复能力或重放副作用。

只有上述检查和清理全部成功且子进程正常退出时，才输出 `f17-native-full-import / import-recorded`，附带 `taskUnchanged / archiveVerified / metadataRecorded` 三个 true。启动器按所选模式隔离输出，其他模式的成功不能通过；不输出文件路径、任务 ID、令牌、异常或原始数据库内容。失败／超时不证明没有已归档文件或记录，仍保留本次私有根，不自动重试或删除已发布文件。

新增实现已通过参数／输出过滤及静态隔离检查，并编译两种模式；本轮没有运行 Electron 或 Windows。成功仅有待原生环境证明该固定样本的首帧和本地归档组合，不能等同于全片解码、用户素材兼容性、普通安装版验收或远程成片下载恢复。PRD RUN 02 的已有远程执行待下载恢复仍是独立待办。
