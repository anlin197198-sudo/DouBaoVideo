# F10 独立临时编辑区

当前镜头／首帧／尾帧格式预览通过空槽选择门禁后，可明确点击「在临时编辑区准备」。编辑区是独立组件内存，不是正式提示词编辑框，不经过 `TaskCanvas.onChange` 或自动保存控制器。

## 操作与范围

只有目标正文不存在或精确为空、结构化字段已明确填写、当前身份和保存状态有效时可准备。手动空白文字仍受保护，视频位置不开放该动作；未知参考图对应关系不会被略过。准备前重新核验当前预览及上下文，不把字段完整视为语义已审核或可以发送。

准备后保留当时原文和独立编辑文字；每次改动只影响缓冲区，最多 10 万字符。明确复制才写剪贴板，没有写入项目、保存、核对或确认按钮。来源随后改变只提示旧缓冲区与当前预览不一致，不覆盖已经编辑的文字。

「恢复准备时原文」只丢弃缓冲区内编辑并回到捕获的原文，不从当前新预览覆盖；关闭编辑区丢弃缓冲区。切换提示词位置／任务、端点身份改变或关闭整个面板均会卸载并清空，界面提前说明。收起预览或同一位置重新渲染不隐式清空。

## 复制与兼容

剪贴板成功反馈必须仍属于同一缓冲区会话及同一文字。关闭后重新打开即使文字相同，旧异步复制结果也不能显示为新编辑区的成功；复制失败保留文字，可手动选择复制。

没有数据库、工作区模型或备份格式变化，不上传素材，不使用外部模型或 DeepSeek，不接提交或队列。正式提示词仍由原编辑区和既有保存路径管理。本编辑区不替代人工审核和发送前校验。

新增 3 项合成状态测试，全量 `npm test` 235/235（0 失败、0 跳过）、类型检查、生产构建及 `git diff --check` 通过。独立复审无阻断且纯函数定向 3/3 通过。测试覆盖明确准备、独立编辑／恢复／关闭、不变性、来源陈旧、空槽门禁及关闭重开后的复制轮次隔离。真实 UI 生命周期、剪贴板和 Windows 未运行验收；既有第三方 `use no memo` 构建警告非阻断。
