# F13 同尝试证据聚合（纯内部边界）

V1.19 云端增量，基于 0b2fbe9。承接单条回执分类，仅提供有界证据集合的本地归并，不查询或发送远端请求。

## 判定原则

- 全部证据只相对于同一尝试、任务、账号、输入修订和快照摘要分类，复用现有严格分类器。调用者不能用另一个尝试的成功改变本次结果。
- 已验证受理身份保留；迟到未知、超时或畸形观察不能擦除它，也不能产生重试权限。
- 不同已受理远端身份，或已受理与明确未建任务同时出现，必须人工核实。重复相同受理不构成冲突；未知观察不能解决冲突。
- 所有结果不允许无条件重试，不宣称视频完成，不产生队列、执行记录或 UI 状态更新。

## 信任及保存边界

“已验证”必须由未来可信协议适配器提供；字段解析和本函数归并不认证来源，不证明实际发送，也不检查 F12 文件。当前没有真实适配器，测试全部合成。

本轮最多评估 100 条完整证据集合，不接收可伪造的“上次已成功”累加状态。非法、稀疏、访问器数组或超限列表拒绝评估并进入人工检查，不截断历史；拒绝结果不能当作“没有受理引用”，也不能替换调用方已保存的身份。单调保留只针对仍在上限内、保留全部旧观察并追加新观察的有效集合：调用方删除历史、进程重启或漏传证据不在纯函数的保障范围内。未来必须另外实现可信观察存储、原子更新、跨进程竞争及人工裁决流程。不能宣称持久冲突恢复已经完成。
