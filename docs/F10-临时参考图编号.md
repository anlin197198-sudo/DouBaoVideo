# F10 临时参考图编号预览

V1.19 云端增量，基于 28406da。仅帮助作者在本地预览里声明计划使用的 `@图片N` 对应关系，不代表图片已上传，也不是豆包已核实的输入槽位。

## 范围

- 只列出当前提示词范围内已有镜头关联资产的参考图 ID。镜头提示词用当前镜头，首尾帧分别用首／尾镜头，整条视频用当前镜头集合。
- 同一参考图被多个资产引用时共用一条编号声明。编号由作者填写，不自动分配；允许留空，已填编号必须是唯一的 1–200 正整数。200 是本地编辑上限，不是提供方容量声明。
- 仅凭工作区中的关联 ID 建立计划标签，不验证图片文件存在、字节、摘要、上传状态或提供方支持能力。不读取真实图片或路径。
- 输出在原格式预览末尾单独追加“计划编号”附录，包含资产类型／名称及本地图片 ID，以区分同名资产；不把旧的“上传编号未知”改写成已上传。编号只在当前临时映射预览中保留；任务、修订、资产、关联、端点、风格或预览文字变化后立即失效，即使来源恢复也不自动复活。必须明确重新开始并重新填写。映射无持久化，不进入备份、队列或提交负载。

## 与已有编辑功能隔离

映射预览和复制是独立只读出口，不传入正式提示词的空槽选择器、独立临时编辑区或明确写入动作。已有参考图对应关系缺口不因此消除，F13 能力与素材确认要求也不改变。

作者复制后可自行检查文字，但本功能不会保存、覆盖、确认提示词或素材，更不会调用模型／上传图片。角色、场景、道具仅使用现有相关资产内容，不引入模板样例。
