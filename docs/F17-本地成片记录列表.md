# F17 本地成片记录列表（只读）

依据《界面操作设计文档》成片页默认每任务最新记录、按需查看版本要求，将原占位内容替换为本地归档元数据视图。

- 来源仅为现有 SQLite `films` 与本地任务资料；读取不会创建、修改或删除执行、成片或文件。
- 每个任务默认展示最高有效正整数版本；同版本按有效记录时间降序、记录 ID 稳定排序，缺失时间排在有效时间之后。重复最高版本显示警告，不删除重复记录。旧版本和异常版本号按需展开，全无有效版本时明确不能判定最新。
- 日期只显示规范有效时间；异常日期显示未记录。保留原记录，不发起重做或远端操作。
- 本切片不把旧 `file_path` 作为读取授权或播放器来源，也不向界面传递完整路径。不提供播放、打开目录、导入、下载或媒体登记按钮。
- 本地有成片记录不代表文件已校验、仍存在或可播放；界面明确显示这一限制。不将本地记录视为新增完成验收。

## 验证边界

合成记录写入临时 SQLite 后关闭重开，经实际 `workspace.read` 生产快照及组件静态渲染检查。该测试不等于 Electron 页面交互、视频播放或 Windows 运行验收。当前不接入上一切片的登记文件来源，未来须先建立验证后登记的受管媒体与失败解释。

新增2项回归，覆盖实际 workspace.read 路由／SQLite 重开、不含路径的投影、零写入／会话操作、默认与折叠版本、重复／异常版本、有效时间排序和缺失任务。全量305/305（0失败、0跳过）、类型检查、构建、差异检查通过；浏览器交互与原生页面未运行。

## 记录来源

标准成片页现在只显示“本地导入”或“未确认”。只有成片任务存在、执行关联同一任务，且执行操作与状态分别是本地导入和已登记，同时没有账号及远端引用时才显示“本地导入”。其他、缺失或互相矛盾的记录保持可见，显示“未确认”；历史 `video` 操作名不能证明远程生成成功。

只读投影不会带出原操作字符串、账号、远端引用、执行输入或文件路径，不创建回执或写记录。V7 隔离恢复保留同样的来源元数据，但备份不包含视频，来源分类不保证可读或可播放，也不启用标准应用的导入入口。
