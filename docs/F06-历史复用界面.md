# F06 历史正文明确复用界面

剧本历史面板保留只读查看，并增加两步操作：先预览选中历史正文与当前已保存正文的替换范围，再明确点击「复用为新草稿（将自动保存）」。不会把查看历史当成恢复，也不会覆盖旧历史记录。

## 确认与保存

预览和复用只在没有未保存、保存中、错误或冲突时可用；空历史正文明确警告会清空当前草稿。取消或关闭预览不改项目。复用成功只表示进入普通工作区草稿和现有自动保存，不能误报已保存；保存失败继续使用既有留稿／重试／冲突处理。

主进程仍通过任务限定读取历史和已保存内容，以受限、短时、一次性令牌保留原服务预览对象。渲染器不能拼接历史正文或转移令牌到别的任务。令牌不是持久化数据，不写备份或执行回执；重启后重新预览。

## 并发与原内容保护

主进程采用前复核任务修订与原服务上下文，画布收到异步结果后还会以当前控制器状态再校验。等待期间编辑、保存、切任务或改变上下文，不能让迟到结果覆盖新内容。关闭／更换所看版本后旧响应不再显示或应用。

只有剧本正文按既有规则更新，布局、镜头、资产、关联与提示词原文保留。依赖标记待核对，受影响首尾确认失效；普通保存追加新历史，原版本及当前版本仍可查。没有自动核对、提供方生成或视频提交。

本轮不调用外部服务、DeepSeek、用户样稿或密钥，不修改权限。真实 UI／Windows 和升级环境验收仍待独立进行。

新增 3 项合成回归，全量 `npm test` 250/250（0 失败、0 跳过）、类型检查、生产构建及 `git diff --check` 通过。覆盖可信 IPC／严格参数、跨任务与重放、真实保存变化、令牌期限／容量、迟到新草稿保护及普通保存追加历史。独立静态审查无阻断，审查者未单独运行文件测试；取消用例验证领域结果可丢弃，不代表 React 取消交互验收。真实 UI／Windows 未运行，既有第三方 `use no memo` 构建警告非阻断。

令牌最多保留 32 项，每项 5 分钟；满额提示稍后重试，不静默替换其他预览。身份正确的一次采用请求消耗令牌，即便后续已保存内容变化导致拒绝，也须重新预览。取消界面不写数据，未使用令牌到期清理。读取与草稿接口不生成持久写入回执；实际正文修改仍仅由普通保存事务处理。
