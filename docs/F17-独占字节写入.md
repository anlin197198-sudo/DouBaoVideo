# F17 独占字节写入基础

V1.19 云端增量，基于 644f7fd。承接确定性文件名工具，只提供内部本地文件写入原语，不接下载、UI、数据目录配置或成片数据库。

## 顺序和边界

调用方提供可信本地目标父目录、已核实任务／执行身份、明确版本及已验证媒体的字节流。服务要求正整数预期字节数且不超过8GiB、严格小写64位SHA256，并重新检查精确字节数量和摘要；8GiB是本地资源上限，不是提供方能力声明。这不是媒体格式验证，不能把任意合成字节叫作可播放视频。

同目录独占创建随机临时文件，以最多64KiB私有块逐块写入，不缓存完整视频；调用方给出的当前流块仍由调用方持有，不能据此宣称总进程内存恒定64KiB。字节校验通过后刷盘并关闭，再用硬链接独占发布到命名工具生成的目标基本名。已有目标、文件系统不支持硬链接或权限失败均停止，不回退成覆盖式重命名或复制。

发布前失败只尝试清理本次拥有的临时文件。发布后清理失败不能谎称没有写入；保留最终目标，不删旧文件，不自动重试。任何不确定结果都必须核实本次目标身份和记录，不能盲目新建执行或覆盖重写。

## 返回结果和重试

- published：目标身份已验证且临时路径清理完成，只证明字节发布。
- published-cleanup-failed：最终目标已发布，但临时文件仍保留或清理结果不明；保留目标并核实返回的临时路径。
- not-published：未确认本次发布成功，字节／已存在目标／明确不支持等失败；另看cleanup字段，失败残留也可能需要人工处理。
- publication-uncertain：发布响应或身份无法确定，不能按普通失败盲目重写。

硬链接已成功但响应丢失时，若目标仍是本次临时文件的同一身份，可确认已发布；若无法核实则保持不确定。清理响应丢失会复查路径，只有父目录仍可信且临时文件确实不存在才记removed。所有结果 automaticRetry=false、mediaValidated=false、databaseCompleted=false；不删除最终目标。

## 不承诺的事项

- 不认证任务／执行归属，不分配版本，不写入完成记录；未来应用服务必须保证文件和数据库交接一致。
- 8GiB是字节上限，不是流提供者等待时长保证；输入迭代器挂起／取消策略仍需未来调用层负责，本轮没有后台任务或超时调度。
- 不接受或下载URL，不播放、不解码真实视频，不证明已有媒体校验流程可用。
- 只在可信本地父目录契约下执行。路径身份检查不能代替对恶意同用户进程持续竞态的OS沙箱。
- 基本名长度上限不保证任意父目录／文件系统可用，过长或不支持时拒绝，不换名绕过。
- 文件刷盘不等于跨断电目录项持久化保证；Windows文件锁、权限、硬链接行为及断电恢复仍需原生验收。
