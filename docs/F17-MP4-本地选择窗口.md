# F17：本地 MP4 原生选择窗口边界

新增未接线的主进程适配器，复用 [本地 MP4 摄取适配器](F17-本地MP4接收适配器.md)。只允许主进程用所属工作区窗口选择单个 MP4。先校验任务 UUID、保存修订、窗口及当前编辑会话；对话框返回、文件身份快照、摄取和退出前再次检查。传给可信检查回调的仅有已验证任务绑定、结构证据和一次性流，不传路径；对外结果为固定状态。取消没有文件读取，过期选择不移交；成功、异常和过期都关闭已持有输入。

后续接线需提供工作区窗口及顶部页面版本号，并检查发起的编辑会话（包括任务切走再切回）及数据库保存修订；主动失效可用 AbortSignal，检查器仍需在异步工作前重新检查。过滤器不替代文件验证，结构证据不等于真实解码。任何未来预留、写入或发布都需其自身的持久化防护，本适配器不做这些操作。

没有添加 IPC、成片按钮或可以打开通用路径的能力；不联网，不修改源文件。测试为合成端口替身，不启动 Electron 或验收 Windows 原生窗口。
