# DouBaoVideo

Windows 桌面视频制作工作区，使用 Electron、React、TypeScript、React Flow 和本地 SQLite。

## 启动

开发环境使用 Node.js 24 或更新版本。

Windows 上可以直接双击 [启动.cmd](./启动.cmd)。脚本会在缺少依赖时安装依赖，再构建当前代码并打开桌面窗口。

在 PowerShell 中手动运行时使用 `npm.cmd`。系统限制 PowerShell 脚本执行时，直接输入 `npm` 可能命中被拦截的 `npm.ps1`。

```powershell
npm.cmd ci
npm.cmd run dev
```

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd start
```

Electron 首次运行会下载对应平台的运行时。当前工程使用 Electron 内置 Node.js 的 `node:sqlite`，数据库由主进程统一管理。

## Windows 安装包（开发验证）

在 Windows 构建机上运行 `npm.cmd ci`、`npm.cmd test`、`npm.cmd run package:win`。只验证打包目录时使用 `npm.cmd run package:win -- --dir`。云端已验证 x64 应用目录和图片处理依赖；完整安装包需在 Windows 构建环境生成并验收。操作和验证要求见 [Windows 安装与升级验收](./packaging/Windows-验收.md)。

## 剧本拆解：DeepSeek-V4.1-Flash-1017

DeepSeek 只处理「已保存剧本 → 分镜候选」，不写剧本、不接收资产或视频提示词、不出片。官方托管模型 ID 为 `deepseek-flash`。出片由原豆包 AI 流程处理，真实可用入口未实测。

默认关闭。要启用，在启动程序的环境中配置 `DOUBAO_DEEPSEEK_ENABLED=1` 和 `DEEPSEEK_API_KEY` 后重启。请通过自己的密钥管理方式传入 API 密钥，不要写进代码、Markdown、安装包或公开仓库。剧本保存后手动点「生成分镜候选 · DeepSeek」，确认接收方与费用提示后才发送；取消不发；空画布明确采用后只进入分镜草稿。已有镜头时，只有候选前段逐字段完全一致且末尾有新增，才允许明确追加；否则只预览，不覆盖。详见 [F07 DeepSeek 分镜候选入口](docs/F07-DeepSeek分镜候选入口.md)。

## 本地数据

默认写入 Electron 的应用用户数据目录，工作区信息中可查看实际路径。目录包含 `workspace.sqlite`、`logs`、`media` 和独立账号的会话数据。

开发或测试时可指定一个独立目录。

```powershell
$env:DOUBAO_DATA_DIR = 'E:\DouBaoVideo\.local\development'
npm.cmd run dev
```

写操作使用请求编号保存事务回执。网络重试复用同一请求编号时，已提交的本地操作返回原结果。剧本保存同时核对任务版本，旧版本冲突会保留编辑区中的内容并反馈原因。

## 命令中间件

命令从受限的 preload 桥进入主进程，依次检查窗口来源、请求格式、已注册的命令和业务参数。写操作在同一事务中保存业务数据与请求回执，失败时一起回滚。结果统一携带请求编号，错误转换为前端可展示的类型，日志仅记录操作名称、耗时和错误类型。
