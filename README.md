# DouBaoVideo

Windows 桌面视频制作工作区，使用 Electron、React、TypeScript、React Flow 和本地 SQLite。

## 启动

开发环境使用 Node.js 24 或更新版本。

Windows 上可以直接双击 [启动.cmd](./启动.cmd)。脚本会在缺少依赖时安装依赖，再构建当前代码并打开桌面窗口。

在 PowerShell 中手动运行时使用 `npm.cmd`。系统限制 PowerShell 脚本执行时，直接输入 `npm` 可能命中被拦截的 `npm.ps1`。

```powershell
npm.cmd ci
npm.cmd run dev
```

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd start
```

Electron 首次运行会下载对应平台的运行时。当前工程使用 Electron 内置 Node.js 的 `node:sqlite`，数据库由主进程统一管理。

## 当前可用功能

- 四个主页面和单任务画布。
- 创建七天周计划，启用或暂停计划，打开当天任务。列表进入画布后返回，恢复同计划／日期的滚动及归档／历史日期展开状态（本次会话内）；切计划或日期不混用位置。桌面归档末项进入后返回保留日期／展开／滚动，以及切日重置、审核→画布→列表返回已通过；跨计划隔离仅自动回归验证。
- 编辑计划前预览日期／数量／时间／风格影响；减少明确选择任务移出排期，制作内容保留可打开，增加补建空白任务。当前仅本地排期，尚未启用真实定时调度。
- 编辑和保存剧本、画布位置与视图，关闭程序后恢复已保存内容。
- 手动新增、编辑、排序和删除分镜，展示剧本到镜头的连线；修改剧本后逐镜头提示核对。
- 在画布管理人物、场景和道具，编辑设定、按类型筛选、预览合并重复资产，以及确认删除。
- 导入 PNG、JPEG、WebP 参考图，复制归档并在本任务内复用；资产内容版本、位置和核对状态可恢复。
- 勾选或拖线关联镜头与资产；合并或删除资产时同步迁移、清理引用。
- 手动编辑镜头／视频／首帧／尾帧提示词，设置任务风格，依赖变化时保留文字并提示核对。
- 计划补充风格说明（数据库 V4），任务分别继承或独立覆盖风格与说明，可明确覆盖为空；旧非空任务说明保留。计划编辑预览影响，锁定历史受保护，快速改回也不会恢复旧确认。旧 V3 备份仍可只读验证；桌面 V3→V4 迁移、计划说明影响预览、风格／说明分别继承、独立空覆盖及重启恢复验收通过；旧非空任务说明保留，原提示词文字不覆盖，计划说明输入框全宽显示正常。升级后旧 V3／7 任务／2 图备份验证通过，源文件名单与 hash 不变。74 项独立回归及类型检查通过；快速 A→B→A 防抖保护为自动测试证据。
- 导入、选择和放大两张静态首尾图，保存本地审核确认；输入或图片变化后需重新确认。
- 800ms 防抖自动保存，保存中继续编辑不覆盖新内容；失败保留草稿供重试，返回前保存，正常关闭时保护未保存内容。
- 提示词和首尾图画布节点、只读来源连线、下一步导航及节点位置恢复。
- 尺寸感知“整理布局”：按实测／保守节点宽高分列避让，仅主动整理才重排旧位置；新增节点寻找空位，长摘要折行限高，不修改业务正文、镜头顺序或确认。自动回归与最终桌面压力验收通过：长标题／5 镜头／5 资产／2 图整理无重叠，手拖后新增镜头保留旧位置；重启布局和视图一致，既有业务内容不变。镜头关联资产区域已修复最小宽度，长名称完整换行且无水平溢出。
- 保存版本冲突时比较本地草稿与已保存版本，明确确认后覆盖或放弃，拒绝覆盖再次变化的版本。

- 审核页提示词缺项／待核对原因旁提供准确编辑入口，复用既有提示词面板，不覆盖草稿；保持手动导图无需图片提示词的规则。87 项自动回归通过；桌面视频过期入口定位、核对保存 v4 后转为尾帧阻塞、尾帧准确定位与原文保留已通过，其余分支不冒充桌面验收。
- 添加账号资料，标注会员档位、启停账号，打开各自独立的豆包登录窗口。
- 工作区信息中创建业务数据库与静态图本地备份，系统目录选择、取消无输出、校验后独立发布，不含视频文件或应用登录会话。
- 统一命令接口、输入校验、请求编号、事务、重复请求回执、版本冲突和错误日志。

当前处于本地制作阶段，手动制作、提示词、本地图片与审核基础可用，待完整交互和用户验收。开发顺序、功能状态及 L0—L5 级别见 [功能开发文档](./功能开发文档.md)。自动提取、真实生成、多账号派发、定时和成片归档尚未接入，不会把本地图片确认当成视频生成成功。画布自动保存，也保留“保存画布”和返回前保存。强制结束进程或断电时，尚未落库的草稿不保证恢复。

参考图通过系统文件窗口选择，使用 sharp 解码为 PNG 副本，保存于应用数据目录的 `media/references`。输入最大 20 MB，边长最多 8192 像素，总像素不超过 4000 万。原图移动后副本仍可用；替换或移除关联会保留归档图供本任务复用。导入立即归档，资产选择关系随画布保存。当前没有跨任务公共资产库和归档图片自动清理。

## 本地数据

默认写入 Electron 的应用用户数据目录，工作区信息中可查看实际路径。目录包含 `workspace.sqlite`、`logs`、`media` 和独立账号的会话数据。

开发或测试时可指定一个独立目录。

```powershell
$env:DOUBAO_DATA_DIR = 'E:\DouBaoVideo\.local\development'
npm.cmd run dev
```

写操作使用请求编号保存事务回执。网络重试复用同一请求编号时，已提交的本地操作返回原结果。剧本保存同时核对任务版本，旧版本冲突会保留编辑区中的内容并反馈原因。

## 命令中间件

命令从受限的 preload 桥进入主进程，依次检查窗口来源、请求格式、已注册的命令和业务参数。写操作在同一事务中保存业务数据与请求回执，失败时一起回滚。结果统一携带请求编号，错误转换为前端可展示的类型，日志仅记录操作名称、耗时和错误类型。

豆包页面使用独立的会话窗口，应用业务接口只接受主工作区窗口的调用。接入模块当前明确返回能力待验证状态。
