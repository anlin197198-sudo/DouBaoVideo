# Windows 本地制作离线验收

只验证周计划、剧本、图片选择、保存与重开；不验证豆包／DeepSeek、播放、安装升级或正式交付。仅限明确授权的独立普通 Windows 测试用户或隔离虚拟机，不用正式电脑账号、素材、登录会话或默认工作区。需要严格断网时使用事先准备好的离线虚拟机，不修改防火墙或工作机设置。

1. 记录 Windows 版本、应用版本、代码 SHA、本次使用的解包目录和该处 `DouBaoVideo.exe`、`resources/app.asar` 的 SHA-256（可用 PowerShell `Get-FileHash -Algorithm SHA256 -LiteralPath <文件>`）。使用可信的实际解包产物，**不是安装器**；先按 [静态包验收](Windows-验收.md) 核对。
2. 在已存在的专用本机测试父目录生成样本：`node packaging/make-offline-fixture.mjs --output-parent "C:\test-private\doubao-fixtures"`。无参数仅显示帮助。程序只新建独立子目录；返回三份合成文件的名称、长度、SHA-256。首帧是浅蓝底左侧白圆，尾帧是橙底右侧白方块，均为 320×180 PNG。不要放入真实文件。
3. 将一次启动用的父目录专门留空，记录该次创建的唯一隔离根。用 [隔离启动契约](Windows-隔离启动烟测.md) 显式启动已核对的 EXE；核实是本次子进程的窗口、初始工作区为空。关闭须由操作者在确认窗口归属后正常进行。现有启动观察器只做有限时观察；如需更长交互，在同一受控测试窗口继续，并另行记录真实关闭。观察器退出、启动成功提示或退出码不是界面验收。
4. 建一份合成周计划，在任务画布粘贴 `script.txt`，等待显示已保存。手动建两个镜头。分别用原生文件选择对话框导入 `first.png` 与 `last.png`，明确设为当前首帧和尾帧；确认没有选反。若要验收审核，再手动写入视频提示词并按现有要求完成核对，执行明确确认。
5. 等待画布保存后从画布返回，正常关闭。只在同一个独立测试工作区中以原有隔离环境重启；**不要**双击应用走默认数据目录，也不要用启动器再次创建新根后声称原工作区重开成功。由测试工程人员按隔离契约保留本轮私有环境并显式复用。检查同一任务正文与两张角色是否恢复；若有实际确认，检查确认是否真实保留。未完成重开就记录“未测”。
6. 只记录实际观察到的窗口／输入／文件选择／保存／重开结果及失败步骤；记录 fixture 摘要，截图仅保留合成内容。不加载账号、不点击生成，不上传文件或诊断日志。

此文档、生成器和合成回归不代表已经运行 Windows。
