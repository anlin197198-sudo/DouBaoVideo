# Windows 解包产物隔离启动烟测

这是面向获准的 Windows 测试工程人员的 Node 24 启动器，不是安装器、不改系统设置。脚本能追踪它直接启动的子进程和退出，**不能检测窗口或证明渲染成功**。本轮只在云端核对脚本并用合成替身运行测试，尚未启动 Windows EXE。

## 运行前

1. 在独立普通测试用户中执行，确认无已有 DouBaoVideo 进程；否则单实例机制可能将启动交给旧进程。不要为测试结束其他用户或已有实例。
2. 先完成 [静态包验收](Windows-验收.md)，核对可信来源、版本和 EXE／app.asar SHA-256。启动器只核对 EXE 名称、PE32+ x64 头、相邻 app.asar 和本地路径结构，**不是签名或完整性验证**。使用普通本机磁盘，不用映射盘、网络共享、链接或目录重定向；不要让其他进程替换包或测试父目录。驱动器字母本身不能证明是本地盘。
3. 用测试用户自己的私有本机目录作为已存在的测试父目录，不能选包目录。脚本创建新空子目录，不复用以前目录，也不回退默认工作区。先获得本次运行授权。严格断网需预先受控的测试环境，脚本不改防火墙。

## 执行

从已具备构建依赖的仓库运行，脚本不会安装或下载工具。下列路径只是例子。路径含空格时保留引号。

```powershell
node packaging/smoke-windows.mjs
node packaging/smoke-windows.mjs --run --exe "C:\artifact\win-unpacked\DouBaoVideo.exe" --parent "C:\test-private\doubao-smoke"
```

第一条只显示说明；第二条只在 Windows 创建本次测试根并运行明确指定的解包 EXE，不搜索或下载任何文件。仅给子进程传递列出的系统定位变量和新建的 DOUBAO_DATA_DIR、HOME／USERPROFILE、APPDATA、LOCALAPPDATA、TEMP／TMP。禁用 DeepSeek；不传 API 密钥、调试渲染地址、NODE_OPTIONS 或 Electron 命令行绕过项。独立用户仍是必要前提；这不是操作系统沙箱或断网保证。不点击账号、生成或外链，不导入真实素材。

启动观察最多 30 秒。根据输出 PID 人工确认窗口确实来自此次启动，而非同名窗口或旧实例；另核对标题、空工作区、无旧任务／账号。观察结束后，在核实窗口归属的前提下人工正常关闭，脚本再等待最多 10 秒；也可在人工观察结束后立即正常关闭。若无法核实，记录未验证，不自动关闭。非零或提前退出、未观察到退出或无响应要单独记录；**即使记录退出码 0，也不自动判定窗口、渲染或烟测通过**。脚本不终止任何进程或子树，不按进程名查杀，不会删除合成目录；超时后进程可能仍在运行，只按本次核实的身份人工处理。

- 本次直接子进程 PID 与观察结果：
- 人工核实窗口归属／标题／空工作区／无旧任务和账号：
