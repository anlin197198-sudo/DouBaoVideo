# Windows 隔离启动烟测：执行契约与记录表

基线 ab8fb72。本轮只交付清单，不交付可执行 PowerShell 启动器。云端没有 pwsh／powershell，不能验证 PowerShell 解析或 Windows 窗口及子进程归属；未经验证的自动关闭脚本可能误关已有应用。没有安装工具或启动 EXE。

## 未来启动器的强制条件

- 必填字面绝对 EXE 路径和独立 -Run 开关；缺少任一只说明、不启动。不搜索用户文件，拒绝 URL、UNC、通配符、目录及安装器。确认相邻 resources/app.asar 存在，不自动下载补件。
- 使用获准的独立普通测试用户。操作者先确认无已有该应用实例，不能按进程名批量终止旧实例；启动转交旧实例或自身退出不能算本次窗口通过。
- 在该测试用户私有本地目录独占创建随机全新空根，不接受已有业务目录。创建失败即停止，绝不回退默认工作区。不能靠修改权限使失败路径继续。
- 仅为子进程构造必要系统环境，明确 DOUBAO_DATA_DIR、HOME／USERPROFILE、APPDATA、LOCALAPPDATA、TEMP／TMP 到本次测试根对应的新建子目录。不改变父会话／系统环境，不输出原环境值。
- 显式 DOUBAO_DEEPSEEK_ENABLED=0；不传 DEEPSEEK_API_KEY、其它凭据、ELECTRON_RENDERER_URL、NODE_OPTIONS 或 ELECTRON_RUN_AS_NODE。不读取或打印密钥值。
- 使用 ProcessStartInfo 显式文件路径和 UseShellExecute=false，不拼接 shell 命令、不关闭沙箱、不改执行策略或安全设置。失败只记录阶段与脱敏错误，不自动提权重试。
- 启动观察最多30秒，窗口须属于本次返回的进程身份；同名窗口、旧实例窗口不能充数。非零窗口句柄仅证明出现窗口，仍需人工确认标题、空工作区且无旧账号／任务。
- 只观察本次窗口，不读取其它窗口／桌面，不点击账号、生成或外链。提供方禁用不是操作系统断网，不能因此宣称零网络流量；严格离线需预先受控环境，脚本不得修改防火墙。
- 先请求正常关闭本次窗口，再最多等待10秒。如需终止，只允许本次创建且身份仍能核实的进程和已验证子树；PID重用或子树归属不明则停止自动清理，报告人工处理，不按名称杀进程。
- 保留本次合成目录供检查，不自动递归删除，也不清理用户默认数据或以前测试目录。

## 人工执行顺序

1. 取得该次 Windows 测试授权，准备本地解包产物，记录代码版本、EXE／app.asar 摘要和 Windows 版本，不记录用户名或凭据。
2. 核对上述条件。没有已验证启动器时，不直接双击 EXE，避免使用默认应用数据；由测试工程人员准备受控子环境。本清单不是已存在的脚本。
3. 仅核对初始窗口和空数据。发现旧计划或账号立即停止，不继续操作。不要登录、导入真实素材或调用生成功能。
4. 正常关闭并确认本次进程退出；不能确认归属时不自动终止。记录失败与未测项，不以窗口出现替代完整验收。

- 新合成目录成功创建、无默认数据回退：
- 子环境隔离及提供方禁用已核对（不附环境转储）：
- 启动时间／本次进程身份／窗口出现结果：
- 人工观察标题、空工作区、无旧账号和任务：
